# GRAIN 纹理噪声场逆向笔记（历史假设，2026-10-11）

> 2026-10-13 纠正：后文 Gabor 排除/唯一性结论已被恢复的实际 shader 源码推翻。统计拟合并未识别真实生成器。当前基线以 [恢复工件](grain-shader-recovered/PROVENANCE.md) 与六图重算为准；Gabor 仅是可选的自定义材料，不能宣称 Figma 精确实现。以下保留原实验过程以便核账。

依据 `texture-ramps-2026-10-08/`（256×256 真实 Chrome 1× 导出，x/y 双向灰度
坡面，未裁剪纹理 radius=64，noiseSize 8/16，无饱和内区提取）。
复现脚本：本目录 `grain-ramp-analysis.py`（统计指纹）与
`grain-model-selection.py`（线性最小二乘模型选择）。

## 最终结构判定（模型选择战役结论）

**GRAIN 位移场不是任何格点插值噪声族，而是非平稳窄带随机场（稀疏卷积 /
Gabor 型）**。证据链：

1. **无 seed（.fig 实测）**：`figma-materials-native-2026-10-08.fig` 内 9 个
   GRAIN 效果全部只含 `noiseSize/clipToShape/radius` 等字段，全文档 0 个 seed
   键；kiwi schema 的可选 `seed` 字段 UI 从不写入。噪声场是 noiseSize 的固定
   确定性函数。
2. **位移幅度 ≈ ±0.44×radius（p95），与 noiseSize 无关**：四组样本的
   (p95−p5)/2 均为 27–30px（radius=64）。分布中心集中（p25..p75 ≈ ±10px）；
   正尾更长（可达 +50~60px，在渐变起点处产生成块黑色钳制伪影，团块尺寸随
   noiseSize 缩放——这不是斑点叠加层，中段阈值覆盖率与纯渐变完全一致）。
3. **方格格点族系统性排除**：线性 LSQ 扫描 格点 4..32 × 相位 {0,0.5} ×
   插值 {smoothstep, quintic} × {值噪声, 梯度噪声} × 倍频组合（含当前内核的
   S/S/2/S/4 形状与粗倍频 32+16+8）× 旋转（−12°..12° 细扫 + 0..90° 全角度
   扫描），R² 全部卡在 0.45 平台。**管线自检：对模拟 3-octave Perlin 用正确
   基拟合 R²=1.0000、部分基的 R² 与理论幅度占比吻合**——排除可信，非管线
   bug。
4. **simplex（三角格点）同样排除**（峰值 L=11，R²=0.47，同天花板）。
5. **格点线对齐判决定案**：二阶导数峰值像素对 x/y mod 4/8/16 无任何聚集
   （直方图平坦）。值/梯度噪声的曲率不连续线必然对齐格线——全部双线性
   格点族被物理排除。
6. **全局正弦条纹排除**（K=8..24 方向 × 多频bin，R² 最高 0.31 且随方向数
   缓慢增长）——能量弥散在窄带内而非少数全局条纹。
7. **正向指纹（非平稳窄带场）**：
   - 径向自协方差呈贝塞尔形：零点 0.93×noiseSize、负谷 −0.11@1.25×noiseSize
     （size 8）、2×noiseSize 处回零；size 16 同形放大；
   - 谱峰 2×noiseSize，与载波波长 λ=2S 的 Gabor/带通噪声一致；
   - **局部方差成块**：16×16 tile 方差 CV = 0.32–0.46，为平稳随机场期望
     （0.088）的 4–5 倍，远超模拟 Perlin（0.17），逼近滤波白噪声（0.48）；
   - lag-1 相关 0.90（平滑）、无平铺（≤64px）、尺度自相似（8↔16 全部指标
     按比例）。
   - 与模拟对照：gaussian-blur 白噪声 kurtosis 3.37 / CV 0.48；Perlin 2.56 /
     0.17；实测 2.7–2.8 / 0.32–0.46，位于两者之间偏滤波白噪声。

**结论**：生成器为"正弦载波（波长 2×noiseSize）+ 随机局部包络"的稀疏叠加
（Gabor noise / Lagae 2009 一族，本项目文献清单里已有此候选），或等价的
"白噪声经带通/核滤波"。当前内核的 3-octave Perlin 族（无论 Q19 表位级复现
多精确）在此结构上不可能收敛到 Figma 的 GRAIN。

## Gabor 参数拟合结果（2026-10-11 第二轮，`gabor-fit.py`）

结构判定后立即完成参数拟合，全部结论可复现：

**模型**：`d(x,y) = Σ_k a_k·cos(2πf·(u_k·(p−c_k)) + φ_k)·G_σ(p−c_k)`，核中心
c_k 取 4px（noiseSize=8 时）网格，每中心每方向一对线性 (cos,sin) 系数。

**拟合质量（诚实验证）**：
- 留出一半像素的 held-out R²：Gabor 0.92–0.94，格点梯度基线只有 0.23；
  参数量对等时（~2000 参数）也是 0.61 vs 0.23——结构优势与参数量无关；
- 全数据拟合 R²=0.988，残差 RMSE 1.67–1.75px（量化下限约 0.3px，余量为
  核形状/频率微差）；
- **结构迁移完美**：y 通道（另一噪声通道）R²=0.988；noiseSize 16 按
  σ×2、载波×2 换算后 R²=0.988——尺度律精确成立。

**恢复的参数（noiseSize=S, radius=R）**：
- 载波波长 ≈ 2.1·S（S=8→17px，S=16→34px；谱环拟合独立给出 1.89–2.15·S）；
- 包络 σ ≈ (2.5, 3.5)·S/8（两正交方向不对称比 ~1.4，但 x/y 拉长互换时
  held-out 相同 0.942/0.943 → 整体各向同性，不对称性属于单个核沿自身
  载波方向的拉长）；
- 核稠密：90% 能量集中在 38% 的中心；幅度分布 platykurtic（超峰度
  −1.14），非稀疏冲激；
- 方向分布严格各向同性：4 个方向块能量 [0.242, 0.239, 0.269, 0.250]；
- **输出映射严格线性**：三次/非对称增益映射的拟合系数≈0（a=1.0006,
  b=−0.0022），d = n 直接成立；此前观察的正尾不对称是钳制伪影+有限样本。
- 幅度标定：p95 位移 ≈ ±0.41·R（R=64 → ±26px）。

**字节级对照（合成坡面 vs 真实 PNG，干净区 n=29314）**：
- 4 子采样合成（模拟 Figma 内部 2× 下采样）：字节全等 7.95%、≤1 灰度
  24.0%、≤2 灰度 39.0%、mean|Δ|=3.9 灰度、max=34；合成图存于
  `grain-synth-x8.png`。这是**用拟合系数**复现的結果——证明结构正确
  （当前 Perlin 内核连这个量级都不可达），剩余差距=核形状精确化+生成器
  确定性常数（hash/相位）未识别。

## 核形状精确化与参考生成器（2026-10-11 第三轮）

**核形状扫描（held-out R²，`gabor-fit.py` 框架扩展）**：
- 包络形状：**Hann 余弦窗一致优于高斯**（0.9559 vs 0.9436）；
- 沿载波拉长饱和于 along 6–10 / across 3–4；更长核的提升来自吸收低频
  漂移（held-out 会奖励平滑趋势外推），**结构真值以指纹匹配为准：
  σ ≈ (5, 4.5)·S/8**；
- 核心间距 3px → 0.9584（小增益）；
- **双载波抖动（每方向 0.9f/1.1f 两档）→ held-out 0.9596 最佳**——与实测
  宽谱环（能量跨 0.4–1.35 f₀）互相印证：真实生成器存在每核频率抖动。

**幅度标定定律**：位移 std = radius/4（p95 = 1.645·R/4 = 0.41R，与实测
±26px@R=64 精确吻合）。

**参考生成器**：`gabor-generator.py`——按上述模型实现（Hann 窗 Gabor、
抖动稠密网格、各向同性方向、载波 2.2·S、std=R/4），占位 PRNG。指纹对照：
p95 ±27.6（目标 ±26）、kurtosis 2.97（目标 2.7–2.8）、径向自相关核心段
(+0.94/+0.78/+0.57 vs +0.90/+0.76/+0.58) 精确匹配；负谷略深（−0.16 vs
−0.11）与 tile CV 略高（0.55 vs 0.33–0.45）指向真实核密度更低/幅度分布
更宽。样本图 `gabor-generator-sample.png`。**给内核移植的蓝本即此文件。**

**引擎常数搜索（负结果，同样有价值）**：fullscreen/render-worker/jsvm
三个 WASM 与 166 个 JS chunk 中均无 sin-hash 家族（12.9898/78.233/
43758.547）、黄金比例 hash（0.618/0x9E3779B97F4A7C15）、PCG/LCG/MMIX
常数——GRAIN 生成器的随机源不是这些常见 hash，常数可能表化或内嵌烘焙
噪声纹理（GRAIN ≤64px 不平铺与 ≥256 的 baked 纹理不矛盾）。

## 对当前实现的含义与下一步

- **实现方向**：在 `texture_noise` 中以稠密 Gabor/粒状合成替换 Perlin 族。
  蓝本：`gabor-generator.py`（Hann 窗、σ≈(0.62,0.56)·S、载波 2.2·S 带每核
  抖动、方向均匀、网格 S/2 抖动、std=R/4）。
- 剩余到字节全等的两件事：①核形状/抖动律精确化（held-out 已到 0.96，
  全拟合残差 ~1.5px，目标 <0.5px——离线继续收敛空间有限，主要靠②）；
  ②生成器的确定性常数（hash/烘焙表）——引擎 RE 未搜到常见 hash 常数，
  需要新探针或引擎数据段分析。
- 需要 Figma 编辑权限时补 3 个探针即可钉死公式：noiseSize 4/32（确认
  尺度律外推）、各向异性 (8,16)（方向行为）、radius 扫描（幅度律）。
- frost 的 128px 平铺与 GRAIN 的不平铺并存，说明两者不可共用同一噪声源
  假设；玻璃 frost 已有 Q19 表复现路径，本笔记只约束 GRAIN。

## 边界

- 坡面在饱和端（<40 或 >215 灰度）与钳制样本（t<12 / t>244）不可恢复位移，
  已用掩码剔除；早期未剔钳制像素时 R² 被拉低至 0.22 属提取伪影。
- 2× 内部采样密度下的下采样会轻度压制高频，但不改变负谷/谱峰/方差成块的
  定性结论。
- 频谱低频端（>60px）含坡面残差漂移，不作为噪声低频证据。
- "Gabor 型"是结构级判定（窄带+局部化+非平稳），具体核形（高斯/余弦窗等）
  与冲激分布尚未识别，需上述参数拟合阶段完成。
