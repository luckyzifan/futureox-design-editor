# 画布模糊算术迭代，2026-10-29

用户授权：对照父目录 core 的 Sketch/Figma 逆向资料迭代渲染器，评估模糊无需逐位精确。此授权覆盖本轮画布近似实验；不将旧全精确合同当作禁止实验的理由。

问题：普通 117 新高倍率视口秒级精修，GPU 精确滤波 fallback 成本。G0/G2/G3/G4/G6/G7 受影响。

冻结比较：同一现有 rational 系数包、同一半径/halo、采样相位、源纹理与分条，保持现有 prefix 优先级，仅替换不能使用 prefix 的 RGBA tent 累加。当前阶段不引入降采样、成对硬件采样或猜测 Figma 半径映射。

候选只在 SDR WebGPU 画布呈现进入；PNG、显式 readback、HDR、软件剖面、Gaussian/box、标量 alpha 及其它效果保持旧路径。每个像素通道出现负数、>1 或非有限 tap 则执行原 rational fallback。

数值门（运行前冻结）：双轴与最终场景黑/白底合成的未量化 SDR 编码最大误差 < 1/255，alpha 最大误差 < 1/255，无新增非有限输出；被拒绝和 HDR/export 路径要求原始 f32 位一致。正常输入覆盖冲激、梯度、棋盘、透明/钳位边缘、分数半径及真实 117。

性能门：独立 Metal 硬件，同源码交替三组，冷首次编译另记；指定重滤波 operator 中位 wall（含 GPU 完成）改善至少 20%，真实 117 指定视口至少 5%。不得把 shader/operator 改善当整机 P95；33/100ms 仍另验。

取消/回收：沿原 GPU fence 与显存预算，不终止其它任务，不覆盖原件。失败不推广默认。保留本轮修改前文件，回滚校验本轮 after hash。


## Profile 后的范围扩展（数值/速度阈值不变）

首轮真实 117 没有达到 5% 门槛。模式/半径计数与源码复核确认大量 mode22 来自显式 Gaussian 的三轮 box，而非 tent。扩展同一有理系数浮点 reducer 至明确 u39=2 的 box；仍保持原六次 H/V 存储舍入边界与精确系数，加入双轴 box oracle 和真实三轮 Gaussian 场景。旧运行记录保留。实验开关统一命名 VITE_DESIGN_CANVAS_BLUR_FLOAT。


## 用户后续明确范围

以下载目录拓扑素材为主，覆盖所有模糊类别。完整源与真实素材工作集分别记录；原件没有的缩放/渐变/tent/玻璃用素材副本补测并标明。数值门不变。完整源包含既有蒙版白板失败，按 FAIL 保留，不能用其它视口或算子通过替代。原件逐页盘点、数字启用标记修复和正式构建 GUI 检查均已记录。
