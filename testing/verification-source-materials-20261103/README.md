## 缩放中的清晰度

缩小且倍率不高于 25% 时可以降低当前计算密度。持续放大时，合成器收到更高密度的可见瓦片才推进清晰度层级，仍保留更清晰的旧瓦片。首次单次跳转直接请求目标密度。覆盖不足时，源缩略图仍显示在缺口下方。停手后的整视口使用目标设备采样相位。

## 画质与边界

Sketch 原生导出同一视口作为独立参照。七个重效果视口的中心颜色与尺寸在测量文件中，尺寸相同时还记录全画布 RGB 每通道平均绝对误差。Sketch 文件保持只读，测试切片来自临时副本。不同实现的字体、颜色管理及滤镜算法会影响跨应用的差异。

大范围自身阴影和高斯只降低软滤镜中间网格的密度。尖锐的轮廓、描边、遮挡和最终显示依旧使用目标画布密度。合格的嵌套高斯按子图层分别解析、滤波、按原始顺序混合，再做父组滤波。只在能证明被不透明内容完整覆盖时跳过后方绘制。精确导出、HDR 与其他绘制入口继续使用各自的采样策略。

## 重放

从仓库根目录执行，需要本机原始素材文件和项目依赖。第二条命令传入新的输出目录。

```sh
node frontend/design-desktop/scripts/build.mjs --fast
node testing/verification-source-materials-20261103/matrix.mjs "/path/to/拓扑素材.sketch" "/tmp/unused-material-report"
```

用 `VERIFY_ONLY` 指定逗号分隔的源 ID，`VERIFY_LIMIT_MS` 调整观察窗。设置 `VERIFY_WHEEL=1` 并只选一个 ID 可同时输出原始滚轮回执，`VERIFY_PIXELS=1` 保存目标密度的 PNG。产物和原件均在本地。

## 可复现的门槛

源文件不入库。连续放大回放使用 `VERIFY_PERCENT=36 VERIFY_WHEEL=1`，初始视口不预热 3200% 高密度瓦片。设置 `VERIFY_REQUIRE_BUDGET=1 VERIFY_BUDGET_MS=1000` 可使任何未达标项产生非零退出码。

生产渲染提交 `c86c332c` 首次全量回放 306 项全部完成，271 项低于一秒。本文顶部的全量复测包含滚轮交接提交 `9bed1c68`。表中四组独立倍率切换及七个高密度像素视口来自相同的静态渲染提交。六个样本比较两档软滤镜采样，所有通道最大差值不超过 1 个 8 位色阶。浅色「6」在 400% 相同视口与旧的完整滤镜路径也进行了逐像素对照，最大差值见测量文件。
