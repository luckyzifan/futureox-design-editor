## 对齐

对照 Mac gaps5 的取样，不是 figma.com。

- **选区**：描边约 `#4597F7`，大约 1pt。四角有白底手柄。尺寸药丸例如 `60 × 47`，蓝底白字。旋转标记仍在角外，指针进入才显示。工具栏强调色仍是 `#3459d4`。
- **悬停**：同一支蓝，只有轮廓。没有手柄，也没有尺寸药丸。空白画布上没有这支蓝。
- **框选**：拖动时填充约 `#DCE9F5`，边是同一支蓝。松开后相交的图层都进选区（例如 3 个）。X 或 Y 不一致时检查器显示 Mixed。
- **红色间距**：`#E05634`。距离是药丸（例如 `1`）。间隙两端有刻度。画板空白处仍是四边内边距。不穿透已选图层去量后面的对象。
