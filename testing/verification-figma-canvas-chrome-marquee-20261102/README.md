# 画布选区、框选与测距（2026-11-02）

对照 Mac 桌面 Figma 的选区描边、拖动框选和按住 Option 的红色间距。网页和 Electron 共用 `design-client`。不改光栅、瓦片、预算或实验开关。没有设计 API 浮块，也没有协作服务器。33/100ms 与完整 G2/G5 未运行。

## 对齐

- **选区**：包围盒是 2px `#3459d4`。四角是 8px 白底方块，描边同色。尺寸在包围盒下方，蓝底白字。旋转标记仍在角外，指针进入旋转热区才显示。GPU 叠层用同一蓝色，不再画 `#0d99ff`。
- **悬停**：1px `#859be5`，没有手柄，也没有尺寸。多选成员仍是 1px `#3459d4`，悬停不会被看成又一个选中对象。已选图层上不再画悬停。
- **框选**：过 3px 才提交。相交即选中；没碰到的不选。编组按整组选，⌘/Ctrl 深选子级。Shift 在按下或松开时加选，不把已选项剔掉。短拖动仍是点击。
- **红色间距**：按住 Option/Alt，且工具是选择、没有拖动、没有按住空格时，红线 `#f24822` 量到指针将选中的那一层。指针停在已选图层上时不穿透到后面的图层。同级只画正间隙；选区在画板内、指针在画板空白处时画四边内边距。端点仍是 6px 刻度。
