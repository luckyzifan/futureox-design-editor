## 改了什么

分析剖面的覆盖是四张二值采样面，不透明实色在覆盖为 1 时 source-over 的结果就是源像素。面积至少 160×120 的区域改成按行填充这段实色，边缘仍走原来的混合。更小的区域留在原来的逐像素路径上，因为第一次不设面积门槛时，`01有料素材.fig` 的 zoom 2 帧变慢了。

整块矩形直接铺满的第二次尝试测完后没有留下。它没有把效果关掉的高倍帧再往下做。
