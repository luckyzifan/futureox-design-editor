# 单独 material 候选的 117 实机对照

`material-control-117` 与 `material-candidate-117` 均已完成实际 Electron / Metal 运行，主测试错误与各阶段最终错误均为 0。候选只单独开启 `VITE_DESIGN_DISPLAY_MATERIAL_SOURCE=1`；顺序/原图整视口、清晰缩放、密度超前和跨帧 scratch 均关闭。**候选默认关闭；后续独立真实 GPU 泛化画质门已明确失败，不能发布为已通过画质验收的优化。**

两次原始 117 文件 SHA、harness SHA、1,851 项构建源码清单完全一致，包含相同的新控制柄导入器和 composite 缓存修复；16 个最终相机/DPR 状态逐项一致。源码清单汇总 SHA 为 `f3696877a7be571505fcfc479502e181e06af7219b3381f0087c4adab8e6f4d8`，两边实际捕获的 WASM 均为 `d2a6069e5da8abf3c1f7f86bc7bd1cd22de7396527c5f9e877f7138c65f97071`。每边 42 个运行资产的已记录哈希均复核一致；三项原生程序在生成本摘要时也与 release 程序逐字节一致，但该复核不是运行时捕获的原生身份。各自 manifest、compiled worker、记录、PNG 的 SHA 和核对范围均保留在 [material-summary.json](material-summary.json)。构建 manifest 不自行记录环境开关，开关配置与编译后 Worker 资产需一起理解。

两次真实拖动均改变了文档且节点数不变，完整文档撤销回到各自操作前哈希；导航、连续 wheel 和导出保留文档，原始 Sketch 文件未变。两个独立导入的文档身份不同，不能用跨运行文档 SHA 不同推断编辑损坏。真实记录中的诊断错误事件计数按 reason code 原样保留，未猜测其分类，也未与最终 harness 错误混为一谈。

本对照不能证明全程无模糊、无白块或所有导出场景精确。以下后续质量门不能被上面有限 117 样本的较小误差抵消。

## 后续独立真实 GPU 质量门：失败，继续默认关闭

`gpu-material-quality-v4` 完成 40 场景、每场景两轮，共 80 组双 GPU 对照。两边均为真实 PNG 原生解码、生产上传和原生区域编译；对照为原四相精确 GPU renderer，候选也以 `readback=false,present=true` 运行。只在 finish observer 中读取真实 target 作为证明，不因 API readback 而关闭候选。SDR 数值经过产品 sRGB/Clip 编码，并非直接截断线性 RGB；这些证明回读的等待不属于交互延迟。

门槛在观察前固定为：最大 RGBA8 分量差 ≤8，平均 RGB 分量差 ≤1，平均 alpha 差 ≤1（均为 0–255 字节单位），原始 GPU 非有限分量必须为 0。结果有 **26 组、对应 13 个场景超过门槛**；最大差 **51/255**，最坏平均 RGB 差 **12.3766/255**。所有原始分量有限，但这不能抵消可见颜色误差。实际执行了 33 次候选构建和 33 次命中，其中各 1 次来自精细边界检查前的重新预热；主对照本身为 32 构建、32 命中，不是全量回退得出的自证。

8 个拒绝场景（四个图边 ROI、两个旋转、两个透明源）共 16 组对照，候选构建/命中均为 0，真实精确 GPU 回退的 raw 差异及非有限值均为 0。两条已预热的精细边界也通过：`readback=true,present=true` 与 `readback=false,present=false` 均实际关闭候选、清掉候选缓存，合计比较 24,576 个 raw 分量，差异为 0。这只覆盖该图像 ROI 的两种边界，不是全部导出场景的无差异证明。

前面三次失败证据原样保留：首次 observer 未在 driver park/reuse 前恢复，旧 closure 错拦新一轮 flags；第二次候选覆盖不足且末尾提前 throw，丢失逐 case 摘要；第三次 primitive rectangle 生成 tag4，未满足生产 tag3 区间资格，实际候选未执行，全回退的零差异不能算候选通过。v4 使用真实非矩形 vector 外轮廓和 native ROI，预检 40 个 tag3、20 个主要场景完整覆盖后，才得到以上有效且失败的质量结果。

1,122 项输入前后哈希稳定，浏览器错误 0；WASM、完整结果、fixture manifest 和各模式误差的去标识核对见 [material-quality-summary.json](material-quality-summary.json)。原始文档、像素、日志和全量运行目录不纳入提交。**不放宽门槛，不称无差异通过；候选继续默认关闭。**
