# 原型播放、嵌套布尔、插件夹具与静止图导出（2026-11-02）

对照 Mac 桌面 Figma 的原型过渡和本机插件宿主。不改编辑器光栅、瓦片、预算或实验开关。强调色仍是 `#3459d4`。没有设计 API 浮块，也没有协作服务器。33/100ms 与完整 G2/G5 未运行。没有 Electron GUI 点击记录。MP4/WebM 没有在这里接上；那条编码属于产品里的 Rust FFmpeg 接口，本面板不调用系统 PATH。

## 原型播放

- **溶解**：过渡方式选「溶解（透明度）」时，预览把上一帧和下一帧各画一次，再用缓动透明度交叉。这两张画面是结算后的文档，中间帧不调用智能动画采样，所以玻璃和模糊不会在每一帧重算。改这一项发生在编辑草稿里；校验先把草稿解开再克隆，否则选择会弹回「智能动画」。
- **播放**：点击带有跳转的热点会切到目标画板。智能动画计划如果准备失败，跳转仍然发生，只是没有中间帧。热点按场景包围盒摆放，盖住看见的形状。
- **智能动画**：匹配图层的透明度和变换仍由内核插值（半程透明度是两端的中点，平移同理）。进度严格在 0 和 1 之间时，预览把图层模糊、背景模糊和高斯模糊半径封顶到 12，玻璃的深度、折射、色散和倒角也封顶。进度到 1 时用原稿，不保留封顶。这不是把效果删掉，也不是 33/100ms 通过。
- **仍未做**：逐节点的智能动画在玻璃封顶之后仍会按采样文档重画；没有测量过它在 Electron 里是否顺。加载动效仍是既有界面淡入。没有逐帧视频导出。

## 画布

- 只选中一个布尔，且它里面还有布尔时，内层先按自己的运算烘焙，再参加外层运算。两个重叠矩形做减去，再和外层联集，孔会留下。
- 多父级粘贴、实例旋转粘贴、Shift+E 和布尔混选展平已在 `bc10d69`（PR #37）进入 main。画布呈现续在 `a5bf523`（PR #38）。这一支在那之上重放。

## 插件

- 插件面板增加「加载插件压缩包」。`.zip` / `.figma` 里只能有一份 `manifest.json`，读完走和文件夹相同的宿主。启动扫描仍然只认用户数据目录里的插件文件夹，不执行压缩包。
- `frontend/design-client/plugins/layout-kit` 是本机夹具：`clientStorage`、纵向自动布局、本地组件和实例、解除编组、一张 CRC 正确的 1×1 PNG。早先那张 IDAT 校验和不匹配，渲染会拒绝。没有下载或运行商店插件。
- 面板上的覆盖表是 `plugins/rich-host/coverage.ts`。`plugins/coverage.ts` 仍是更早的 worker 列表（48/27/22），面板不跑那一套。PNG `exportAsync`、远程组件和原型反应仍不支持。

## 导入导出

- 桌面 Blob 下载现在接受 `.svgz`，和导出面板里的 gzip SVG 一致。`.fd` 仍走保存 / 另存为，不从这块下载放行。
- 导出面板文案改为：这一版仍只写静止图像。视频编码不在本面板，也不假设 PATH 上有 FFmpeg。
- `.fd`、JSON、SVG、FIG、Sketch、PDF 和 PNG 的原有导入没有改语义。GIF 图片和四边独立描边几何仍未做。
