# 玻璃、圆角与渐变的画布操作 — 2026-11-02

桌面 Figma 的复杂外观在这块画布上分成两件事：玻璃跟着每个角走，以及圆角、玻璃光线和渐变可以在画布上改。蓝色强调色仍是 `--workspace-accent`（#3459d4）。选择描边和这些手柄仍是 `#0d99ff`。

不改合成预算、瓦片导航、采样或实验开关。平滑圆角、任意路径和带网络的形状仍走原来的距离场玻璃。33/100ms 与完整 G2/G5 未测，不算通过。

## 玻璃

零平滑的矩形、画板和分区在四角半径一致时，解析玻璃字段与原来的单半径路径相同，序列化也不写出 `radii`。四角不一致时，每个象限使用与填充相同的拟合半径（相邻角共享一条边时按比例缩短），位移和照明仍用原来的圆角盒公式。平滑大于 0、椭圆、编组和矢量网络继续用距离场，因为那条路径跟着真实轮廓。

## 画布操作

- 选中矩形、画板或分区时，四角内侧有圆角手柄。拖动把四角写成同一个半径。按住 Alt 只改被拖的那一角。
- 有可见玻璃效果时，手柄沿解析光照方向放在形状外侧。角度 0 指向下方，与内核光线一致。Shift 按 15° 吸附。
- 最上层可见填充是无变换的线性、径向、角度或菱形渐变时，画出渐变线和色标。末端外侧的手柄改 `angle`，Shift 按 45°。色标沿线段改 offset。已有 `transform` 的渐变不在画布上改，避免换成另一套坐标。
- 属性里的圆角在四角相同时是一个字段。独立圆角按钮展开左上、右上、右下、左下。四角不同时直接显示四个字段。平滑滑块还在。

SVG 导出和拖动时的 SVG 预览仍是原来的玻璃近似，不是这条解析字段。
