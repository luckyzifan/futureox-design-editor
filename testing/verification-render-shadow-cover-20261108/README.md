## 查到的路径

`render_rgba` 走 `render_scene`，`synchronized` 是 false，所以是一张表面加 `area()` 覆盖，不是四张二值采样面。四张采样面只在同步的四平面路径上。效果开启、zoom 6.4 的孤立帧只画了 4 个节点（剔除 183），同时活着的表面像素峰值是 2988096。模糊的常量 0/1 窗口一共跳过 3588226 个像素，仍有 893918 个走原来的求和，有理核回退只有 266 次。那次孤立帧仍在 1686–1872 ms，和改之前的 1782–1872 ms 没有拉开，所以没有留下。

留下的改动在外阴影着色：源像素 alpha 已经是 1 时，阴影画在它下面，双线性取样不会出现在结果里。孤立帧的像素哈希仍是 `c54f50b9145cbfeb8ca0153b80d332db699e6c4081c213832de7f0cb222993ca`，时间从大约 1782–1872 ms 降到 1468–1578 ms。下面的表是完整阶梯，不是孤立帧。
