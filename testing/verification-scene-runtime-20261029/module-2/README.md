**需求集和正确性边界**

目录首次建立时，从已验证的完整场景包读取源模型，用同一 Engine、字体资源和布局求解器生成输出范围。导入布局提示不参与漏载判定。目录绑定不可变描述符及该次字体/布局状态，尚未实现增量目录发布。

当前加载粒度为素材根子树。对象查询会提升到完整所属子树，以保留父布局/变量模式语义；组件主件、插槽、覆盖中的组件交换和连接器目标递归补齐。跨页组件也通过同一源目录读取。背景/未知光学读取保守补齐前序绘制根；动画、全局交互、页面根蒙版或不再中性的舞台保留全量需求。

输出范围和读取范围分别处理。普通裁绘继续采用原有 WorldSupport 规则；需求目录的输出证明允许蒙版和背景模糊的保守几何并集，并将读取依赖交给闭包。颜色控制保持 alpha、不会扩展像素支持范围，因此不再被当成未知背景读取。其他未知效果继续保守处理。

`LoadedDemand` 不是 Document：查询结果明确区分 Loaded、Cold、Absent。未加载记录保持源身份，不能据此删除对象、保存局部源或直接导出。记录损坏、代数不匹配、取消及缺失依赖不会发布成功的半份需求。取消在文件读取和需求迭代中检查；首次完整布局仍是待拆分的粗阶段，未承诺它的取消延迟。

稀疏需求沿用按节点认证的磁盘查找。需求覆盖全部节点时改用顺序校验读取，避免 N 次二分/校验路径放大；该路径不解码全局元数据。没有调整分辨率、四采样、HDR/export 算术或 GPU 预算，也未启用既有实验开关。
