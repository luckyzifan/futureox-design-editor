## 计时拆开

在留下这次改动之前，用 `Date.now` 把同一帧拆开。效果开启、zoom 6.4、总时间 1481.909 ms：准备 174 ms，覆盖光栅 485 ms，高斯模糊 453 ms，整个外阴影调用 505 ms。效果关掉、zoom 32、总时间 371.541 ms：准备 19 ms，覆盖光栅 211 ms，模糊 0。常量 0/1 窗口那次没有再试。

留下的做法不是改模糊核。外阴影画在不透明填充下面。高斯三盒半径之和，加上设备像素上的偏移和扩展，是它能碰到的距离。视口整块落在填充内部、并且比这个距离更靠里时，视口像素不会变。这种帧不再为光晕扩大图层，也不再调用模糊。阴影边缘仍在视口里时，模糊照旧。

孤立的 zoom 6.4 帧在改完后是 696.607 ms 和 706.486 ms，像素哈希仍是 `c54f50b9145cbfeb8ca0153b80d332db699e6c4081c213832de7f0cb222993ca`。效果关掉的 zoom 32 孤立帧是 366.451 ms，哈希仍是 `fa2835198c64056c09afa224ec100c8cc937ed85d20d2c08860d43bd44559d8b`。
