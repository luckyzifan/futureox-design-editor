## 留下的改动

外阴影着色只对 alpha 做和 `sample_linear` 相同的一次双线性，不再把另外三个通道也插一遍。扫描行填充的尝试让同一台机器上的阶梯变慢，没有留下。GPU 字节高斯（mode 22，`u(9).w > 1.5`）改成每条扫描线滑动整数和的 compute pass；分数半径、tent 和浮点有理核仍走原来的逐像素循环。这台机器没有 GPU，compute 路径没有出像素。`slide-blur.wgsl` 能被 naga 解析。没有做降采样模糊。四张采样面没有各自再模糊。
