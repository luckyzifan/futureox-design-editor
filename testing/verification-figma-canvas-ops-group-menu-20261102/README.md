# 画布操作对照：编组与右键（2026-11-02）

对照已采集的 Mac 桌面 Figma gaps3（空选区方向键、编组点击、Enter、空格拖动、选中矩形的右键顺序）。不改光栅、瓦片、预算或实验开关。选区蓝仍是 `#3459d4`。右键底色仍是 `#2c2c2c`。没有设计 API 浮块，也没有协作服务器。33/100ms 与完整 G2/G5 未运行。

## 对齐

- **编组**：普通点击子级实形选中编组。Mac 上 ⌘ 点击选中子级；Ctrl 点击仍是右键，不改选区。其它平台用 Ctrl 深选。双击选中子级。画板子级实形仍选子级，画板空白仍选画板。
- **Enter**：选中编组时选中全部直接子级。Shift+Enter 从子级或从这组子级回到编组。不写历史。
- **空选区方向键**：Arrow 和 Shift+Arrow 不平移相机，也不微移。
- **空格**：对象已选中时先按住空格再拖，相机平移，对象坐标不变。绘制形状时按空格仍移动草稿、不改尺寸。
- **右键**（选中矩形，自上而下）：复制、粘贴到此处、粘贴替换、复制/粘贴为、移动到页面、置于顶层、置于底层、编组、创建选区画板、展平、轮廓化描边、用作蒙版、添加自动布局、创建组件、插件、显示/隐藏、锁定/解锁、水平翻转、垂直翻转。没有描边时轮廓化描边仍列出并禁用。插件子菜单打开现有插件面板，并列出已启用的本机插件。不加入 Figma Make、查找相似、Add motion 和小组件。
