## zoom 3.2 里是什么

玻璃着色之后，效果开启最慢的一帧是 zoom 3.2。同一视口的计时探针（`Date.now`，没有留在这次的 WASM 里）把 839.370 ms 拆成：准备 167 ms，分析覆盖光栅 28 ms，高斯模糊 359 ms，外阴影整段调用 454 ms，玻璃 0 ms，绘制 36 ms。这一帧只有 4 个节点。玻璃不在画面里。阴影层是 430416 个像素，最大层是 476134 个像素。外阴影模糊是这一帧的大头。

同一探针里，zoom 0.8 仍是准备、玻璃边缘、看得见的阴影模糊。玻璃层 24505 个像素，阴影层 166617 个像素。没有再改已经证明的玻璃内部取样。

## 留下的和丢掉的

阴影 alpha 里，若一个矩形的整个方形邻域（半径是三次盒半径之和）都是精确的 1，这个矩形在每次盒卷积之后仍是 1。面积至少一半时，这一段直接写成 1，卷积从段尾重新求和。面积不够、或表面小于 160×120 时，仍走原来的整段卷积。

孤立帧像素没变。zoom 3.2 仍是 `9c342bcedc9349495cedc5065352c7db31032a5b364ca6ad519bd59fe4753410`，两次 803.656 ms 和 811.623 ms，再一次 798.793 ms（改动前同一次会话的孤立帧是 828.840 ms）。zoom 0.8 仍是 `ce06260b0d0ac332f0eecd59f580e81a85e40c897e841289331b1aa0e4d4eb09`，656.709 ms 和 657.826 ms（玻璃着色那次的孤立帧是 658.990 ms）。zoom 6.4 仍是 `c54f50b9145cbfeb8ca0153b80d332db699e6c4081c213832de7f0cb222993ca`。效果关掉 zoom 32 仍是 `fa2835198c64056c09afa224ec100c8cc937ed85d20d2c08860d43bd44559d8b`。

丢掉的是同一种内部矩形的另一种做法：把四周条带各复制成一张小表面再模糊。像素哈希相同，但 zoom 3.2 孤立帧变成 1016.268 ms 和 1018.966 ms，比改动前的 828.840 ms 慢。条带的捕获区叠在一起，模糊时间从 359 ms 升到 450 ms。没有留下。

没有改实色行填充、不透明取样跳过、常量 0/1 窗口跳过、视口内跳过、覆盖跨度，也没有改玻璃的覆盖盒和内部单次取样。
