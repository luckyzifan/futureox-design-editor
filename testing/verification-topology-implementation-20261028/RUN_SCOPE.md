# 拓扑渲染实际优化：冻结范围

用户授权落实此前的优化计划并真实测试。基线为当前含未提交修改的工作树，`baseline.json` 固定逐文件hash；现有纯色段/渐变融合默认策略、常量覆盖opt-in、两瓦片流水线和所有预算/精度要求保留。

优先故障：局部视口首块十余秒准备；全览300秒未完成（首块约25万draw）；运动中旧纹理8倍放大及完成后的后台尾部。先采样/分段，再实施命中热点的变化；脏区空间合并、字形实例化以其前置热点和精度门为准。

保留标准：同层RGBA32F严格逐位一致（含signed zero）或相应缓存/传输的精确字节oracle；真实拓扑同输入配对至少三次，中位端到端改善至少5%，相关场景不得退化。旧失败/新通过、取消/晚回/原件hash、真实GPU/GUI与未验边界分别记录。源容量不改，不能降低采样、扩大内存、截断效果或删除guard。

真实性：生产Rust native/WASM准备、Worker WebGPU与NativeSourceSurface；优化涉及Rust时重建实际产物。采样运行与性能运行分离，性能期间本任务不并行构建/重测试。全G2绝对延迟目标未制定，保持BLOCKED；不以局部通过替代全G5。

停止边界：只取消本任务预览和自有测试进程，保存超时与失败。用户下载目录原件只读，编辑/保存/导出验证使用隔离副本或工作区。所有候选保留基线与可核对的回滚文件，最后只合入已经证明成立的变化。
