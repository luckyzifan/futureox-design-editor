# 验证状态与适用范围

本包是最新冻结源码的开发增量。各组件证据来自不同时间、不同运行环境和源码快照，**不能相加为本包最终组合的通过数**。打包期间只做文件校验、补丁应用/回滚和保护测试，没有重新运行完整功能测试。

## 明确没有声称完成

- 最终源码匹配 WASM 的完整回归与压力验收。封包时新的开发 WASM 已构建，但不随本包分发。
- 最终全项目 TypeScript 类型检查。
- 十份大文档同页的最终内存边界和性能目标。
- 真实 Electron/GPU 的 32→1/2/3/4/5 缩放像素完整性、连续缩放后编辑/撤销与真实屏幕姿态。
- 商业发行级断电、文件系统错误、UI、OS 对话框、整机资源压力和迁移恢复验收。

32 MiB 不可信外部导入/归档安全边界和其他独立协议/剪贴板/GPU预算仍然保留，不能把“大文档容量改进”理解为无限制接受所有外部输入。

## 证据的解释

负控、基线失败、突变失败和候选通过应分别阅读。被系统终止、缺少前提、TODO、跳过、真实 socket 权限不足都不是通过。已有 431b7395 WASM 的 SHA-256 为 `431b7395cd7666b08872fc72942ef1f9ffe3a06f501467770a84a1102a146416`，它不在本包中，也不匹配最终组合。

整理后的证据记录只保留结果、来源日志文件名及 SHA-256，不包含原始用户日志、私有测试样本、云环境绝对路径或内部协调记录。
