# 图层、属性与右键菜单（2026-11-02）

对照 Mac 桌面 Figma。蓝色强调色仍是 `#3459d4`，选区与画板标题用 `#0d99ff`。中文为默认，English 跟着顶栏语言。未改光栅、瓦片、预算或实验开关。

## 对照

| 桌面 Figma | 这次 |
| --- | --- |
| 普通图层：面板从上到下是从最前到最后 | 保持。子节点仍按从后到前存储 |
| 自动布局：面板从上到下是流的顺序，第一项在最上面 | 自动布局父级不再把子级倒序显示。拖到某一行的上方会插到流的更前面 |
| 双击名称重命名；眼睛和锁不触发重命名 | 双击名称才进入重命名。眼睛和锁挡住双击 |
| 隐藏只把名称变淡，锁和关闭的眼睛一直可见 | 隐藏不再把整行降到 50% 不透明度 |
| 选中行是 Figma 蓝，悬停只是浅底 | 选中文字 `#0d99ff`。去掉悬停蓝框 |
| 在画板里、且不在自动布局流中，才有约束 | 约束图只出现在画板或分区的子级上。绝对定位的自动布局子级仍可约束 |
| 约束图：点边选择，Shift 点对边变成两边固定 | 位置区有同样的图。比例缩放仍用下拉 |
| 自动布局对齐是九个点 | 横向和纵向布局有九个点。两端对齐仍用下拉 |
| 旋转：逆时针为正，范围到 ±180，最多两位小数 | 检查器角标 `∠`。显示 `formatFigmaAngle`。Shift 把图层自己的角度吸到 15° |
| 画布上旋转时，右侧角度跟着变 | 跟手读数不走 80ms 面板节流，也不必等文档预览 |
| 画板标题默认灰色，选中变蓝。单个非画板在框外显示蓝名 | DOM 和 GPU 标签同一套颜色和名称 |
| 画布底是浅灰，标尺是白底灰字 | 底色 `#e5e5e5`，标尺白底 |
| 右键：复制、剪切、粘贴、创建副本、删除，然后复制/粘贴为、层级、编组、自动布局、组件、显示/锁定、翻转 | 菜单按这个顺序。选择图层仍在最上方。移动到页面在菜单后部。撤销和重做留在最后 |

## 还没对齐

- 画布堆叠「最前 / 最后」没有单独字段。FIG 导入仍按 `stackReverseZIndex` 改子级顺序。
- 宽高芯片继续用精确设计单位。检查器尺寸也不四舍五入成两位。
- 工具栏仍在底部。检查器里还有大量中文在选 English 时不切换。
- 右键没有插件子菜单。
- 这不是 33/100ms，也不是完整 G2/G5。
