# 画布操作对照：粘贴、Shift+E 与展平（2026-11-02）

对照 Mac 桌面 Figma gaps4 记录（不是 figma.com）。不改光栅、瓦片、预算或实验开关。选区蓝仍是 `#3459d4`。没有设计 API 浮块，也没有协作服务器。中文和 English 界面都还在。33/100ms 与完整 G2/G5 未运行。没有做 Electron GUI 点击。

## 对齐

- **不同父级的多选粘贴**：Mac 桌面实测（gaps4）里，⌘V 和 Paste Over Selection / 粘贴到原位都把副本留在原来的画板里，不落到页面。普通粘贴在父级坐标上 +10；粘贴到原位不步进，世界位置不变。选中一个画板再粘贴，整份仍进这个画板。父级锁定时拒绝。
- **旋转实例**：普通粘贴和粘贴到原位都保留旋转。30° 的实例粘贴后线性部分仍是 30°，普通粘贴的平移再 +10。主组件粘贴成实例时同样保留整段仿射，不再只留下平移。
- **Shift+E**：Mac 设计模式按 Shift+E 打开原型页，不是轮廓化描边。这条和现有命令一致，没有改开。矢量编辑里 Shift+E 仍切橡皮。轮廓化描边是 ⌘⇧O（Windows / Linux 是 Ctrl+Shift+O）。
- **混选展平**：布尔联集和旁边的矩形一起 ⌘E，收成一条矢量，没有拒绝提示。减去留下的孔也还在。单个布尔、两个矩形、文字拒绝仍是原来的结果。

## Electron 复现

1. 两个画板里各放一个矩形，同时选中，复制，⌘V 或 Ctrl+V。每个副本应留在自己的画板里，检查器 X/Y 比原来大 10。再复制后选「粘贴到原位」，副本仍在各自画板里，位置不步进。
2. 从矩形创建组件，放一个实例，旋转到 30°，复制再粘贴。新实例的旋转仍是 30°。
3. 选择工具下按 Shift+E，右侧在设计 / 原型之间切换，不要轮廓化描边。有描边的形状用 ⌘⇧O（Windows / Linux 是 Ctrl+Shift+O）轮廓化描边。
4. 两个矩形做联集，再和旁边的矩形一起选中，⌘E 展平。应得到一条矢量，没有拒绝提示。一次撤销恢复。
