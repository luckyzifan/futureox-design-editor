# 画布操作对照（续）（2026-11-02）

对照用户本机 Mac 桌面 Figma 的实测（空选区方向键不平移、编组点击、Enter、右键顺序）。不改光栅、瓦片、预算或实验开关。选区蓝仍是 `#3459d4`。右键底色仍是 `#2c2c2c`。没有设计 API 浮块，也没有协作服务器。33/100ms 与完整 G2/G5 未运行。没有做 Electron GUI 回归。

## 对齐

- **编组**：普通点击选中编组。⌘/Ctrl 点击子级实形选中该子级。双击选中该子级。点在画板子级实形上仍选子级，点在画板空白处仍选画板。已经选中画板时，双击先进入编组，再双击选中子级。Enter 选中编组的直接子级；Shift+Enter 回到编组。布尔组同样先选整组。
- **空选区方向键**：不平移相机，也不微移。Arrow 和 Shift+Arrow 都是 0。有选区时仍是 1px / Shift 10px。
- **空格**：先按空格再拖，仍是平移。对象拖动中再按空格，仍保住拖动开始时的父级，不改父。绘制形状时按空格，形状跟指针走、尺寸不变；松手时空格仍按着则不掉进下面的画板。松开空格再拖，继续改尺寸。
- **粘贴**：同一父级里多选后粘贴，副本留在这个父级，各自 +10。选中一个画板、分区或编组再「粘贴到原位」，副本进这个容器，世界位置不变。选中的是普通形状时，粘贴到原位仍放在页面上。⌘D 和普通粘贴的 +10、Option 拖动跟指针，保持上次的行为。

## 右键菜单

选中形状时按 Mac 桌面实测顺序：复制、粘贴到此处、粘贴替换、复制/粘贴为、移动到页面、置于顶层、置于底层、编组、创建画板、展平、轮廓化描边、用作蒙版、添加自动布局、创建组件、显示/隐藏、锁定/解锁、水平翻转、垂直翻转。不加入 Figma Make、查找相似和小组件。剪切、副本、删除、上移一层仍留在快捷键里。空选区是粘贴到此处和全选。
