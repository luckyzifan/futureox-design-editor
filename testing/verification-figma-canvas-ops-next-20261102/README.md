## 对齐

- **编组**：普通点击选中编组，不选子级。点在画板子级实形上仍选子级，点在画板空白处仍选画板。⌘/Ctrl 深选始终是同一个子级。双击从编组再进一层。已经选进编组后，同级点击选中那个子级。布尔组同样先选整组。悬停轮廓跟这次点击。框选在页面上圈住编组时选编组；⌘ 框选选里面的子级。
- **空选区方向键**：仍按 20 / Shift 100 CSS 像素平移相机，不跟 1 / 10 的图层微移。放大后世界距离变短。画板等工具待命、没有选区时也平移。这和 Figma 键盘说明一致，不是缺口。
- **空格**：先按空格再拖，仍是平移。对象拖动中再按空格，仍保住拖动开始时的父级，不改父。绘制形状时按空格，形状跟指针走、尺寸不变；松手时空格仍按着则不掉进下面的画板。松开空格再拖，继续改尺寸。
- **粘贴**：同一父级里多选后粘贴，副本留在这个父级，各自 +10。选中一个画板、分区或编组再「粘贴到原位」，副本进这个容器，世界位置不变。选中的是普通形状时，粘贴到原位仍放在页面上。⌘D 和普通粘贴的 +10、Option 拖动跟指针，保持上次的行为。

## 右键菜单

对象菜单顺序按 Mac Figma：剪贴板、复制/粘贴为、堆叠、编组/画板/展平、自动布局、组件、锁定/隐藏、翻转。空选区只留粘贴到此处、粘贴到原位、全选。撤销、缩放、重命名、选择相同和覆盖粘贴不再出现在 Figma 预设的画布菜单里；快捷键还在。Sketch 预设仍保留覆盖粘贴。选择图层、编辑文字、移动到页面还在。
