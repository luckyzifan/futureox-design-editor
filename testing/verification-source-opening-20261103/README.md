# 拓扑素材多页首屏与按需精修

在项目构建的 Electron ARM64 桌面版中打开同一份原始 Sketch 文件，三个源页面分别有 209、55、42 个顶层素材。对照使用同一构建，关闭打开预览，走完整画板。实验组使用独立的干净恢复目录，分别测量首次打开、同一文件再次打开，以及只访问控件页。各组均保留原始素材。具体输入、时间和原生工作量见 [测量记录](measurements.json)。

首次打开时，第一个素材图在 2,723 ms 解码，2,959 ms 截到首屏。切换三个页面后，各页首个可见素材到两次动画帧分别用时 28、40、28 ms。主动选择全部素材后，冷算完 306 张用时 17,363 ms。再次打开时 740 ms 取齐缓存，新增缩略图渲染数为零。只看控件页的回放中，42 项与打开时的少量预取共生成 46 张，两次观察之间计数稳定，未启动精修场景。

完整画板对照构建了 306 个根、124,447 个节点、300,408,797 字节的快照，用时 13,871 ms。新路径在总览时未请求原生场景，聚焦「模板二」只需一个根、138 个节点、533,847 字节的精修快照，用时 39 ms。全量对照和两个按需精修回放使用相同视口，画板内侧 1,341,928 个物理像素的 RGBA 逐像素相同。测试先进行了切页、截图和全缩略图等待操作，记录中的 fullExact 时刻包含这些步骤。

本次测试覆盖没有未保存编辑的原始文件。缓存通过源内容和预览策略标识校验，已恢复编辑的会话遵守原有修订隔离。前端 37 项、桌面主进程 13 项、原生大型文档 70 项测试通过。另有 11 项原生测试标记为忽略。
