# 渲染路径实现与验证（2026-10-25）

本轮来源是 `39ff10b` 加开始时已有工作区改动。`baseline.json` 保存开始时逐文件 hash；不把 HEAD 当作整个起始工作区。没有提交或推送。

## 实现范围

1. **重效果范围与半径**：Rust 当前页的依赖摘要只遍历该页可达节点，其他页的 noise/backdrop 不再扩大区域判断。现有显式 `VITE_DESIGN_EXACT_WHOLE_TENT_2048=1` 算子支持 retained/capturing 的完整物理源；分段 H/V 保留完整源和完整 H、原始半径、clamp 与 f32 边界。该实验仍默认关闭；未取消 16MP 或旧 512 guard，任意嵌套大效果的默认全应用验收仍需单列。
2. **增量编译**：相同相机/范围/数学策略下，缓存一个不重叠的子树前沿。经过权威变换或材质失效证明的修改仅撤销相应子树；不可证明的拓扑和 painter-stage 变化回到完整编译。缓存与既有 32MiB program 预算共享，最多占其中四分之一。缓存准入先计数，后复制。
3. **物理准备取消**：Rust 节点、几何、扫描线及打包检查点可停止未发布计算。WASM 在支持 SharedArrayBuffer 的环境读取外线程标志；原生 stdin 读取线程把取消送给执行中的准确请求。所有者/顺序/字节账本等待真正回复，编辑与导出不能取消。没有共享内存的浏览器仍保留执行完再丢弃的回退，不宣称具备同步 WASM 抢占。
4. **身份与传输**：当前节点的精确语义证明与传输 LRU 分离，含原始 URI、实际几何字节和子身份，仍共用原内存 allowance。移除节点或无法留存的超限证明不复活旧 ID。逐节点编码减少第二份全场景临时记录；不可变 ScenePlan 复用逻辑拓扑，源对象绑定逐帧独立。
5. **导航成本**：同覆盖优先级内使用已观测请求耗时，4 次老化避免昂贵区域饥饿；连续精修每块释放 mailbox，最多 4 个任务且受实际 16ms 工作预算限制。没有声称单任务可在 16ms 内结束，也未恢复已拒绝的 tile-first 分支。
6. **资源维护**：无压力维护只冻结实际清退所需的最老表面批次，完整存量仍计费；压力路径、pin、完成 epoch 和池 LIFO 保持。不是去掉 GPU 等待，也不是已完成任意渲染图的全局生命周期编译。
7. **批绘**：Rust 计划可签发多个连续不透明同色段，严格保持原绘制顺序；共享透明私有目标完成各段后再发布。短段、复杂效果和不完整证明回退。沿用现有显式 opaque batch 开关。
8. **UI 账本**：两处瓦片淘汰改为事务内增量计费；共享 buffer、GPU 句柄、bitmap、独立 canvas 与 held 别名保留原口径和先后顺序。

## 验证记录

测试过程中保留了夹具缺字段、原生二进制错误转换缺失等初次失败及后续修复日志。最终测试与硬件/GUI 状态见本目录后续结果文件；不能把定向通过、旧构建或局部像素门算作全部 G0–G8 完成。

- `native-full*.log`：Rust 全库与重跑。
- `native-final-gpu.log`：复核后实际编译/包/依赖/批绘路径。
- `frontend*.log`、`typecheck*.log`：前端测试和类型检查。
- `desktop-build*.log`：实际 JS、WASM 和原生桌面构建，保留初次失败。
- `hardware.json`：真实 Apple Metal，完整/分段精确滤波及多颜色批绘浮点位对照。它不证明物理呈现、整编辑器或默认开关验收。
- `wasm-cancellation.json`：独立线程运行实际 WASM，在第 100 个检查点受控暂停后取消，恢复场景与 PNG 核对；不是性能样本。
- `native-cancellation.json`：实际 Node host worker/Rust 子进程取消、恢复和晚取消。
- `ledger-benchmark.json`：独立 CPU 账本对照，不能外推为 GUI 帧率。

完整 G5 的六格、真实 117 十份、100 图标六组导出、所有平台和物理 scanout 必须分别有证据；未覆盖项保持 NOT_RUN/BLOCKED。已有运动失败不能由本轮局部通过自动关闭。
