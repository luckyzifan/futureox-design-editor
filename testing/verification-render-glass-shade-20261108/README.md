## 改了什么

覆盖跨度之后，zoom 0.8 的效果开启帧仍是阶梯里最慢的一档。同一视口的计时探针（`Date.now`，只用于拆时间，没有留在这次的 WASM 里）把 943.772 ms 拆成：准备 162 ms，分析覆盖光栅 18 ms，高斯模糊合计 184 ms，外阴影整段调用 158 ms，玻璃整段 447 ms。玻璃层是 24505 个像素，阴影层是 166617 个像素。分析覆盖不是这一帧的大头。阴影边缘还在画面里，模糊仍在跑，但玻璃着色比它更大。

留下的改动有两处，一起测的：

- 玻璃着色的输出收成覆盖大于 0 的包围盒。覆盖为 0 的像素乘上背景后仍是 0，包围盒外不再做 24 次色散取样。
- 已经证明的玻璃内部，位移在每条色散因子上落到同一个取样偏移时，只读一次背景，原来的加权和仍作用在这一个像素上。

没有改 `paint_region` 的实色行填充，没有改不透明像素跳过双线性取样，没有再试常量 0/1 盒模糊跳过，没有改视口内跳过，也没有改 `area()` 的 0.125 跨度。

同一探针在改完之后，zoom 0.8 是 658.534 ms，玻璃整段 167 ms，阴影 155 ms，模糊合计 181 ms，准备 160 ms，光栅仍是 18 ms。去掉计时后再跑一帧是 658.990 ms。像素哈希前后都是 `ce06260b0d0ac332f0eecd59f580e81a85e40c897e841289331b1aa0e4d4eb09`。效果开启 zoom 6.4 仍是 `c54f50b9145cbfeb8ca0153b80d332db699e6c4081c213832de7f0cb222993ca`，孤立帧 383.518 ms。效果关掉 zoom 32 仍是 `fa2835198c64056c09afa224ec100c8cc937ed85d20d2c08860d43bd44559d8b`，孤立帧 216.952 ms。这一轮改动前，同一会话里带计时的效果关掉 zoom 32 已经是 216.004 ms，所以这次没有改这条没有玻璃的路径。覆盖跨度笔记里的孤立帧 174.004 ms 是另一次会话。

这一轮没有另留一条更慢的变体。
