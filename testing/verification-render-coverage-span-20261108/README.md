## 改了什么

`area()` 仍是八条垂直样本加水平区间。一个像素方块被区间完全盖住时，每条样本加上的是恰好 1/8。这些像素改成一次 `+= 0.125`。两端没盖满的像素仍用原来的区间公式。轴对齐矩形内部直接写成 1。没有改 `paint_region` 的实色行填充，也没有改外阴影的不透明取样或视口内跳过。

孤立帧像素哈希没变：效果开启 zoom 6.4 仍是 `c54f50b9145cbfeb8ca0153b80d332db699e6c4081c213832de7f0cb222993ca`，时间 385.331 ms 和 387.831 ms（上一轮孤立帧约 697–706 ms）。效果关掉 zoom 32 仍是 `fa2835198c64056c09afa224ec100c8cc937ed85d20d2c08860d43bd44559d8b`，时间 174.004 ms 和 174.694 ms（上一轮孤立帧 366.451 ms）。
