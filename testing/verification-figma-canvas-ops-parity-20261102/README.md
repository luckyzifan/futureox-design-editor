# 画布操作与 Mac 桌面 Figma 对照（2026-11-02）

对照用户本机 Mac 桌面 Figma 的三条实测，不改光栅、瓦片、预算或实验开关。选区蓝仍是 `#3459d4`。没有设计 API 浮块，也没有协作服务器。33/100ms 与完整 G2/G5 未运行。

## 对齐

- **Option 拖动复制**：副本跟着指针，原对象留在原地。位移是指针差，不是 ⌘D 的固定 +10。松开 Option 再松手则取消副本、只移动原对象。一次撤销。自动布局副本在松手时收回原来的尺寸策略。
- **方向键**：小步 1px，Shift+方向键 10px。这是默认微移，和本机冒烟一致。Delete / Backspace 删除，⌘A 在已进入的容器里选同级，顶层选区则选当前页。`]` / `[` 置顶 / 置底。
- **嵌套命中**：点在子级实形上选中该子级；点在画板空白处选中画板。编组不再把这次点击改写成编组。⌘ 深选同一点，不论当前是否选中编组，结果都是同一个子级；空白处仍是画板。组件和实例的普通点击仍停在实例上。

另外：右键菜单补了「展平」（⌘E），把同级形状或单个布尔收成一条矢量。键盘缩放从 100% 走到 125%、150%、200%，滚轮和捏合仍是连续的。

## 仍未对齐

- 没有选区时，方向键仍按 20 / 100 CSS 像素平移相机，不跟微移步长。
- 拖动过程中再按空格，仍会保住当前父级；空格先按下再拖，是平移。
- ⌘D 和普通粘贴仍是 +10。只有 Option 拖动跟指针。
- 布尔和其它图层混选时拒绝展平；嵌套布尔不会按各自运算先烘焙再合并。
- Figma 预设里 Shift+E 同时绑了橡皮和原型切换，先匹配到原型切换。这是原有重复，本轮没有改。
