## 修复内容

1. **维护显示模式误强制等待**：显示输出模式不再被当作必须同步维护的理由；仅原有预算、水位、资源量、次数和完成边界约束内的小型临时资源维护可有限延后。必要等待（所需分配、真实压力、退休图片资源、真实读回）不删除，不抬高预算，不提前释放或取消计费。
2. **filter-table 资格顺序**：生成 dense 图片坐标场之前先检查 axes 资格，避免不适用的可选表路径先触发 64 MiB 原语限制；保留精确条带坐标，不降采样质量。
