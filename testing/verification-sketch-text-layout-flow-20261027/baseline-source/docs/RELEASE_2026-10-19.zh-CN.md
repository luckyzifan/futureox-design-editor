# Futureox Design 本地能力与交互性能增量

基准：`71d32153e6f55b3723c99708b4c4c49ac7342e67`。本包只包含相对此版本的修改，不覆盖为更早的渲染版本。日期：2026-10-19 UTC。

## 已实现

- 共享实际编辑器的结构化设计 API：页面/节点/组件/变量/样式/字体、事务批处理、版本校验、撤销重做、本地原型与评论操作。
- MCP stdio 服务与受限本地桌面桥接。授权默认关闭；按文档申请读写；大文件输出使用资源链接，避免巨型 base64 直接灌入模型上下文。
- SQLite 本地配置、操作元数据与记录管理页面；人工操作与自动化分开标记。操作日志与文档快照是不同机制。
- 原生 FD、JSON 追加导入，HTML/CSS、SVG 导出及字体/素材检查。Sketch ZIP 导入导出接入 API 与管理页面，修复原生组件 ID 和支持的覆盖/变换映射。
- Figma-like / Sketch-like 快捷键选择、平台键位提示、右键菜单键盘入口及输入框/IME/模态保护。
- 统一可重复测试入口和 Linux/Windows/macOS CI 定义、公开夹具与严格外部夹具模式、显式失败和跳过记录。

## 性能变化与准确边界

1. Rust 准备缓存减少不必要的整图复制。隔离 ABBA CPU 基准：3,500 节点中位数 32.50 → 26.08 ms；10,000 节点 56.64 → 45.62 ms。已有真正共享读者仍使用写时复制。准备数据一致性与旧实现负对照验证通过。
2. 缩放默认保留 160 ms 静止窗口，消除窗口结束后的额外帧等待。合成调度轨迹准入 P95 183.33 → 166.67 ms。重复突发的渲染数量与接受相机序列保持基线一致。更激进的自适应模式不在默认路径启用。
3. React/jsdom + 实际 Editor/WASM：120 次相机提交不再触发文字属性面板的 120 次无关计算；36 次拖动预览中相同桌面状态发布由 36 次减至 1 次。有效中途更新和最终提交仍可见。

以上分别测量 CPU 准备、调度准入、组件工作量，不能换算成真实 GPU 帧率。最终 3,200 节点 CPU 场景在 10%、100%、400%、3,200% 的像素结果保持一致；不代表全部文件、滤镜或设备的零像素差验收。

## 明确未完成/未验证

- 真实 Web/Electron GPU、实际系统窗口/安装包、三平台输入法与图形驱动尚未验收。
- 本地 socket 监听在当前环境受阻；内存协议与模拟 IPC 的通过不代替真实 socket ACL/原生授权对话框验证。
- HTML 为静态近似设计输出，不包含实际登录业务；字体打包和浏览器表达差异需按返回警告处理。
- Sketch 字体二进制不随导出嵌入；部分不支持的覆盖、缩放/斜切变换会明确拒绝。不能声称完整无损兼容。
- Figma/Sketch 全量本地功能差异见 LOCAL_DESIGN_FEATURE_MATRIX.zh-CN.md。通用原型表达式/状态机、媒体交互、部分画笔/重复变换等仍有缺口。
- CI 文件已编写；本轮未在 GitHub 或真实 Windows/macOS runner 执行。

## 测试质量

新接口的 preload 测试保持精确允许列表，额外检查固定 IPC 路由、只读冻结对象、原始事件隔离和注销。隔离副本故意引入“泄露原始 IPC 事件”和“编辑记录发往错误通道”两种缺陷，测试均以非零退出识别。正常源码通过。负对照不计为产品通过数量。

统一运行器另修复了 Python 全部跳过仍可能通过的问题：全部 skip 或全部 expected failure 必须失败；真实通过与 skip 混合时保留分类。实际子进程反例验证这些门槛；超时且忽略 SIGTERM 的自有子进程会在宽限期后终止，不能无限挂住。

测试入口、环境要求与夹具策略见 testing/README.md。最终逐套结果见随包验证摘要。源代码检查、模拟 DOM、真实 WASM/Rust/SQLite、真实 OS/GPU 必须分开解释。

## 使用

先备份。用随包只读检查器核对受影响文件的精确前像/后像；未知本地修改停止合并，不应强行覆盖。检查器不负责自动写入，也不是原子安装器。合并后按项目构建文档重建前端、WASM 和桌面 Rust 程序。本包不附依赖、编译产物或旧 ZIP。
