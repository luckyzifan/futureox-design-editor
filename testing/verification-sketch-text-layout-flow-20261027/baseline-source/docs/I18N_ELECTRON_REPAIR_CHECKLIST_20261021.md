# Electron localization repair and remaining scope

This record is not a complete-localization or actual-device acceptance claim.

## Implemented scope

- Interface preferences ignore events from a different storage area. A session-only language choice after a failed write is no longer discarded by unrelated sessionStorage updates or clear events.
- The narrow native locale bridge admits only `en` or `zh-CN` through the existing main-process sender checks. App synchronizes the initial persisted locale and later changes without remounting Editor or modifying document/history/dirty state.
- `native-locale.mjs` provides paired native menu labels and open/save/recovery/export/close-fallback text. Native file-filter names follow the active locale while extensions, default paths, cancellation and access checks remain unchanged.
- Canvas context-menu labels, submenu headings and accessible labels switch live. Longer English text triggers repositioning separately from initial/submenu focus, preserving the focused item. Authored layer and page names are untouched.
- Workspace rail, toolbar accessible labels, visible tooltips, tool picker/arrangement labels and command-registry presentation are localized. Explicit ID-based lookups retain command IDs, tool IDs, category, shortcut, disabled state and callbacks. Crop receives a presentation label without inventing a registered command. Existing authored defaults and undo labels are not translated.
- App-menu entries generated by the OS and operating-system file-picker chrome can still follow OS language. Backend diagnostics and automation authorization dialogs remain separate localization scope.

The App wiring test is explicitly source-only, not an end-to-end App interaction test.
