## zoom 3.2 还剩什么

阴影实色核之后，效果开启最慢的一帧仍是 zoom 3.2。上一轮探针里，839.370 ms 的孤立帧是准备 167 ms、分析覆盖 28 ms、高斯模糊 359 ms、外阴影整段 454 ms、玻璃 0 ms、绘制 36 ms。阴影层 430416 个像素。玻璃不在这一帧里。实色核已经把邻域全是 1 的矩形写成 1。剩下的盒模糊仍是看得见阴影边缘的那一圈。

这次没有再改那个矩形，也没有把四周条带复制成单独的模糊表面，也没有做逐窗口的常量 0/1 判断。
