# CPU 区域与切图导出契约

更新：2026-10-06。类型：[实现]；浏览器点击验收待用户本机执行。

这是独立设计内核的 PNG 接口，不依赖聊天、云文档、Core 身份、网络存储或协作服务。Figma 仅是像素语义的对照目标。其他格式能力和 UI 验收不能从本接口的 CPU 测试成绩推导。

## 已实现的调用链

- Rust：`export::region_plan(ExportBounds, scale)` 和 `Engine::render_region_png(&RegionRequest)`。
- WASM：`export_region_plan_json(bounds, scale)`、`VectorEngine.render_region_png(request)`，与 native 使用同一实现。
- 前端：`exportImage` 保留原调用参数，追加可选 `ExportTarget`；`exportPngBatch` 复用一个 worker 和一个不可变文档快照顺序生成多个倍率。
- 编辑器“导出 → CPU PNG 切图 · 1x / 2x / 3x”：页面、选中图层/Frame、自定义区域；倍率可多选，生成后逐份预览/下载，支持取消、重新生成和关闭。
- `KernelClient` 与 render worker 都强制 PNG 使用 CPU。画布后端偏好、设备 DPR、编辑器 pan/zoom 不参与导出。

示例请求（调用前仍由独立内核加载设计文档与所需字体）：

```json
{
  "pageId": "page",
  "bounds": { "x": -12.375, "y": 7.125, "width": 24, "height": 24 },
  "scale": 3,
  "nodeIds": ["icon"],
  "rasterProfile": "analytic"
}
```

`nodeIds` 省略时渲染页面区域；提供时导出选中子树。`rasterProfile` 省略时继承文档/内核默认值。`colorOutput` 可指定已有的色彩空间和 tone-map 合同，仅适用于启用色彩管理的文档；省略时沿用既有 sRGB + clip 默认输出。新切图面板使用此默认值，广色域/HDR 的显式色彩出口仍在现有色彩面板/API。

## 坐标、尺寸与裁切

1. `bounds` 使用布局解析后的文档坐标，X/Y 可以为负数或小数。原点不 floor、不 round；相机始终为 `(-x × scale, -y × scale, scale)`。
2. 输出尺寸为 `ceil(width × scale)`、`ceil(height × scale)`。仅当乘积距正整数不超过 `8 × f64::EPSILON × max(abs(product), 1)` 时消除浮点运算噪声；真实小数不强行取整。正的极小区域至少占一像素。
3. 不把内容拉伸到取整后的宽高。最后不足一像素的区域向右/下覆盖至整像素边界，**不是另加小数 alpha 裁切蒙版**。例如宽 12.25 在 3x 输出 37 像素，实际覆盖宽 37/3 文档单位。需要严格拼接的切片必须共享输出采样网格。
4. 24×24 图标输出 24/48/72；390×844 Frame 输出 390×844、780×1688、1170×2532。任何设备 DPR 都不改变这些尺寸。
5. 区域 PNG 统一使用带 backdrop halo 的瓦片出口，包括小于 512 的小片；覆盖采样策略由整个页面/所选子树的效果支持性一次决定，不因切片内贡献数不同而改变。普通画布 render 仍保留原有自适应策略。相邻切片仅在 `相邻原点差 × scale` 是整数、倍率一致时可逐像素拼接。不同的小数采样相位不承诺字节一致。现行剖面仍保留自身反走样/效果算法，不因此宣称全部 Figma 像素兼容。
6. 输出透明、无编辑网格。颜色/阴影/blur 等仍先按既有内核合成；输出 viewport 裁掉区域以外的像素。

## 三类目标

| 目标 | 边界与内容 |
| --- | --- |
| 页面 | 复用既有可见内容/效果边界计算；留白显式参数，默认仍为 40 文档单位，可设为 0。保留旧页面 PNG/SVG 行为。 |
| 选中图层/Frame | 使用所选顶级节点在世界坐标中的几何包围盒，去掉同时被选中祖先覆盖的后代。Frame 使用自身几何盒；group 使用现行场景的子节点几何合并规则。描边、文字 ink、效果超出几何盒的部分不自动扩边；零面积几何需使用自定义区域。 |
| 自定义区域 | 按用户给定矩形渲染整页，保留该区域所依赖的页面合成和 backdrop。它是临时导出区域，不是持久化的 Slice 节点。 |

选区导出保持原页面绘制顺序、所选节点的世界变换、子树内部 clip/mask/effects；隔离未选中的图层及外部祖先的 opacity/clip/effects。需要祖先和背景合成时应使用自定义区域。原文档不变：内核在已解析布局上暂时替换根列表/根变换，成功与错误路径都恢复。子树内部组件、字体、图像仍使用已解析的原文档资源。

## 资源与错误合同

- 倍率：0.001–128；UI 当前提供 1/2/3x。X/Y 绝对值最多 1e9；边界/倍率必须有限、宽高必须大于零。
- 通用 PNG：最大边 16384、最多 6400 万像素；前端整批总像素也最多 6400 万。先检查全部计划，再创建 worker。
- Figma 剖面和 Managed 16-bit PNG 保留现有 CPU 8192/边、8,388,608 像素上限；Figma 2x 内部采样的倍率上限是 64x。region API 在渲染前检查这些实际限制；通用尺寸 planner 本身不选择剖面。不伪称已有大幅面色彩分块导出。
- 选区最多 1000 个不同节点；空、隐藏、其他页面或不存在的节点明确失败。重复 ID 去重，祖先/后代不会重复绘制。
- 同一批顺序渲染，保留路径和资源缓存；不同时启动三个完整内核。失败/取消/完成均释放 worker，PNG 不再回传无用的完整 linear framebuffer。
- UI 取消/关闭终止当前 worker；重新生成先撤销旧 Blob URL，卸载时清理余下 URL。未完成批次不显示半套可下载文件。

## 兼容与后续边界

原页面 PNG（默认 2x/40 留白）、纯矢量 SVG、保视觉的内嵌 PNG SVG、managed 16-bit 色彩输出以及 `.forma` 设计文件导入导出均保留。SVG 精确子树目标尚未接入，调用者请求时明确报错。没有依赖版本/锁文件变更，没有 GPU shader/native 修改。

后续应分别交付，而不是把本次 PNG 成绩当作完成：持久化导出预设/Slice 节点、逐节点多格式导出、SVG 精确目标/层级保真、更多位图格式、HTML 结构与资源打包、可往返导入的自有交换格式、更大 managed PNG 分块、任意小数相位的统一切片网格策略。

## 验证与本地操作

自动证据见 [CPU 导出台账](../../testing/review/design-cpu-export-2026-10-06.json)。新增 native 测试直接调用真实 `Engine`；前端测试加载真实 WASM，并以可控 Worker 传输桩验证批量/取消/释放，它们不等于浏览器 UI 点击测试。

本次环境不支持前端启动/浏览器验收：系统 Chromium 的本地 socket 被拒绝，云浏览器访问 localhost 被客户端阻止。按用户要求停止重试，保留此状态，交由用户本机测试。以下是尚需执行的本地清单：

1. 在配置好的 Rust 1.96、wasm32、wasm-bindgen 0.2.128 和锁定 Bun 环境中，进入 `frontend/design-client` 执行 `bun run dev`。
2. 打开或新建 24×24 图标，选择它，点“导出 → CPU PNG 切图”，勾选 1/2/3x；下载后应为 24/48/72 像素且无 40 单位留白。
3. 同样验证 390×844 Frame 的三个尺寸；切换画布 zoom 和设备 DPR，尺寸应不变。检查 Frame 内外溢出、圆角、透明边、mask、文字、图片和效果。
4. 打开切图面板后，在按钮/面板上按 Delete、Backspace、Enter、撤销，确认底层画布未被编辑。自定义负数/小数原点区域；验证尺寸向上取整、内容未拉伸，再测试非法宽高、取消、立即重试、Esc/关闭和再次打开。
5. 验证旧页面 PNG、纯矢量 SVG、视觉 SVG、色彩面板和 `.forma` 保存/重开仍可操作。
6. 可在具备 Chromium 的本机执行 `bun scripts/check-export.ts`；如使用系统 Chromium，设置 `DESIGN_CHROMIUM_EXECUTABLE` 为其实际路径。脚本通过真实 App 导入文件和下载 PNG，检查 DPR 1/2/3 字节一致、尺寸、CPU 路由及取消/URL 回收；本次环境该脚本未通过浏览器启动，不能计入通过数。
