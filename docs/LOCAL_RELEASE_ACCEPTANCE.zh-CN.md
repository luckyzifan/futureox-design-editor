# 本地设计器验收与增量交付

用本次工作区的实际源码构建应用；记录构建输入、JS、WASM、原生进程及打包产物身份。按目标平台实际运行相应检查。发布时分别列出版本号、包目标、已执行项目和待完成项目。[开发契约](DEVELOPMENT_CONTRACT_V1.md) · [包验收](RELEASE_PACKAGE_ACCEPTANCE.zh-CN.md)

| 验收项目 | 需要具备的结果 |
| --- | --- |
| 编辑与文档 | 真实编辑、撤销、重做、关闭重开、失败回执与版本一致性 |
| 导入与导出 | 目标格式、尺寸、颜色、字体、资源和兼容性提示。验证源文件保护与独立工作副本。对支持的整档导出核对重开，对追加导入核对 ID 映射 |
| 本地存储 | 实际 SQLite、文件和恢复路径。检查重启、冲突、回滚、历史恢复及独立副本 |
| MCP | 分别确认操作协议、实际传输、Electron 授权、撤权、Editor/SQLite 链路及外部客户端所需场景 |
| 画布和 GPU | 在实际窗口和目标设备回放。记录准备、提交、完成、当前画面、读回、临界负载和取消结果 |
| 正式安装包 | 核对精确源、包内资源、目标平台、安装、签名、真实启动和变更所需旅程 |

按[渲染优先验收规范](RENDERING_FIRST_ENGINEERING_CONTRACT.zh-CN.md)选取 G 门及固定矩阵。保留未运行、跳过、失败与受阻原因。对高倍率、复杂源文件、HDR 或重效果写清输入与当前显示／导出档位。回归的旧失败与候选通过须落在同一行为断言上。[本地执行命令](../testing/README.md)

增量交付附基准提交、变更路径、前后字节摘要和回滚说明。含用户修改的目的地先核对前像。若交付含已构建产物，须重新确认实际加载的 JS、WASM、原生程序和发布资源。历史性能与早期包结果集中在[验证结论](verification/README.md)。
