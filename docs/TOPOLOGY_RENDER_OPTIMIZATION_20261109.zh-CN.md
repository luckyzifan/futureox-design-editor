# 拓扑素材 GPU 优化与当前成熟度（2026-11-09）

本轮基于 main `ac3c03c4c8082b9a4a7de7746f0ddeeb79db8f40`。以用户拓扑素材为主基准，保留有实测收益的 GPU 批绘，完整撤回未达到收益门的原生投影复用候选。本地继续 GPU 优先、CPU 兜底，原密度、四相、效果与预算不变。

**当前判断为开发者 Alpha：已具备真实复杂文件的落定渲染、编辑与保存能力，画质有较强的限定范围回归证据；大源精修仍约 100 秒，持续交互、跨平台和工程收敛尚未达到生产级。** 测试数量不能替代这个体验差距。

## 实际保留的改动

- 新增 `source-solid-layers.ts`，集中判定批绘准入与不透明 brush 条件。只用于 worker 已认可的原生源 SDR WebGPU 显示、sRGB、四相、物理采样倍率不大于 0.5、输出不超过 514×514 的瓦片。物理倍率包含 DPR，不等于界面显示百分比。
- 连续的不透明纯色填充和描边保持原 painter 顺序，复用既有 native interval program 与 source-layer shader。中心/内侧/外侧描边保留原覆盖与对齐；不合并渐变或半透明算术。
- 只接受已证明为 0/1 的外部裁剪蒙版，软蒙版、效果、复杂混合、回放/光学依赖等保留原路径。批绘范围取节点支持范围并集，使用原区域复制和资源回收边界。
- 沿用既有 uniform 容量、GPU 工作集与缓存上限，没有开启其他 source-detail、数学或导航实验。HDR、CPU/WebGL、精确输出和不受支持的场景继续原路径。
- 默认启用这个窄入口，构建时 `VITE_DESIGN_SOURCE_SOLID_LAYERS=0` 回退。没有新增文档字段、存储迁移或产品面板设置。

## 同条件拓扑对照

Apple M2 Pro / 16 GiB、macOS 26.3、Electron 44.7.0、Apple Metal、DPR 2、1440×960 窗口；同文件、相机与完成条件，重任务串行。指标为点击“精修完整画板”至完整源的当前视口原密度呈现完成，初始打开另计；不是逐帧交互延迟。

| 方案 | 逐次耗时（秒） | 中位数 / 裁决 |
| --- | --- | --- |
| 冻结基线 | 113.001、114.823 | 113.912 |
| 只合并不透明填充 | 105.886、107.737 | 106.811，约改善 6.2%，由下一方案取代 |
| 不透明填充与描边批绘 | 100.548、100.181、101.102 | 100.548，约改善 **11.7%**，保留 |
| 叠加原生投影 superset 复用 | 91.729、101.482、102.145 | 101.482，比 GPU 批绘中位数慢约 0.9%，**撤回** |
| 最终正常构建、无试验开关 | 101.758 | 验证默认配置确实生效；不混作新的配对样本 |

前后实际 draw 计数为 1097119 → 820095，约减少 25.3%；基线计数来自此前诊断回放，计数与性能计时分开。GPU 小场景的更大 draw 降幅没有外推为完整拓扑的提速。

收益门在运行前固定为至少 5% 的真实完成时间改善，并要求最终像素不变。原生复用虽将投影重建从 15 次降至 11 次，增加 5 次 superset 复用，但追加的配对诊断中 native 编译累计 wall 约 25.09 → 25.26 秒，整屏没有稳定收益。因此没有保留该开关、原生代码或测试改动；91.7 秒不是最终版本的性能声明。

## 为什么仍不是成熟产品档次

| 维度 | 目前已具备 | 尚未关闭 |
| --- | --- | --- |
| 落定画质 | 真实拓扑与多文件当前相机的 GPU 像素回归、原密度和效果保留 | 全格式/全部对象的独立保真、跨 GPU/HDR 矩阵 |
| 交互 | 已有连续预览、逐块清晰与限定 GUI 编辑流程 | 大源约 100 秒精修；33 ms 可见 P95、100 ms 精修与完整 G2/G5 未通过 |
| 数据 | 本轮原件保护、撤销/重做、117/FIG 实际 SQLite 重开 | 不能推广为全部异常退出、磁盘故障和版本升级验收 |
| 工程 | Rust 权威语义与 GPU 适配/调度/呈现边界已存在；本轮只保留一个窄入口 | GPU renderer 约 8063 行，worker 2877 行，两套 Surface 2802/956 行；资源、调度与呈现策略耦合仍重 |

“杂乱”的主要负担在策略叠加和大模块的维护成本。本轮采取的收敛是：准入集中到独立模块、复用已有着色器/资源机制、撤回没有端到端收益的分支，并保留单一可复测的拓扑基线。后续仍以完整拓扑、模板二和主框架03为主，117/FIG/test 防回退；再按测得成本拆分 GPU 执行、生命周期、调度与呈现，不靠整体开实验或删除保护层取得快数值。

本机证据位于 `testing/verification-topology-optimization-20261109/`：冻结 scope、各候选、最终 manifest、原件/产物 hash、像素检查、真实 GUI、新进程重开及被撤回候选。私有设计、截图和副本不纳入提交。此前诊断见[复杂拓扑成本分析](TOPOLOGY_RENDER_COST_ANALYSIS_20261109.zh-CN.md)。
