# 本地变量管理

入口：编辑器的「变量」按钮 →「变量与主题」。

- 集合：新建、重命名、切换集合；显示各集合变量数量。
- 模式：切换文档当前模式、设置默认模式、从指定模式复制新模式、重命名和检查删除。每个集合最多 32 个模式。
- 变量：颜色、数值、布尔和文字；按名称搜索、按类型筛选；名称中的 `/` 用于分组。
- 每页显示 40 个变量、3 个模式列。分页只限制当前可见行列，不会删除其他数据。
- 别名只能选择同类型变量，支持搜索。循环别名由现有内核拒绝。把别名转为普通值时，使用正在编辑的模式列；其他集合仍使用其自身的当前或默认模式。
- 选中图层后，可设置局部模式和变量绑定；多选显示混合状态。显式属性编辑遵循编辑器现有规则，包括已选中的锁定图层。

## 输入、撤销与保存

修改名称、数字、颜色或文字后，按 Enter 或移出输入框提交。Esc 取消当前输入。数字可用科学计数法；`10` 改写成 `1e1` 会结束输入，不产生多余历史。

无效输入、输入法组合中的内容和过期输入不会强行提交；切换分页/集合、关闭窗口或替换文档时会保留输入并提示先完成。重新打开同一文档后，新输入归属于新的编辑会话。

使用编辑器统一的「撤销 / 重做」。已提交的变量修改随文档保存；不需要单独导出变量配置。

## 删除策略

点击删除先查看引用检查，再确认。被别名、图层绑定、组件实例覆盖或原型交互引用的变量不能删除；已有变量或局部模式引用的集合不能删除；默认/当前/局部/原型使用中的模式不能删除。请先明确修改引用，不会自动解除绑定或连带删除依赖。删除后可撤销。

模式重命名同时更新变量值、文档选择、图层/实例局部模式和原型模式引用，并保留后续组件模板继承。

## 自动化 API 的组合限制

单次或多次纯模式重命名可原子执行。若同一批操作同时重命名模式并修改变量值或其他设计系统数据，或交换/重排已有模式名，且会影响继承的实例子图层，无法证明安全的组合会整体拒绝，文档、版本与撤销历史不变。错误会提示「请分开操作以保留实例继承」。把重命名和其他修改分成独立调用即可；不会悄悄生成覆盖而冻结继承。
