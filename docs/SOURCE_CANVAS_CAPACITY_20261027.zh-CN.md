# 全源单画布与容量策略（2026-10-27）

用户本轮明确要求取消人为容量上限，并把拓扑 Sketch 全部素材平铺在一个可编辑画板中。此前需要用户选择页面、对象和“上一部分 / 下一部分”的流程不再是目标交互。内部缓冲、传输包、缓存淘汰和光栅任务的粒度可以有界，但不能变成源文件、页面或素材总量的产品拒收条件。

## 已落地的基础

- 源文件容量已有实际存储卷与安全字节偏移约束，不再设固定 4 GiB。此次源 Sketch 索引移除了 4096 归档成员、200 倍压缩比、百万对象、128 层嵌套及 16 KiB 键名的拒收条件。JSON 扫描改成显式堆帧，保留语法、UTF-8、重复编辑键、原始字节位置和取消检查。归档仍校验路径、符号链接、重复成员、真实长度、CRC 和可用磁盘空间。
- `large.canvasLayout` 索引所有源页面的顶层素材，返回原始边界、平铺位置、源身份与完整数量。200 行是一次传输的粒度，可继续读取全部条目。布局边界明确标记为提示，不是裁掉阴影、描边或其他内容的光学边界证明。
- PNG 分行解码取消了源 URI 12 MiB、8192 尺寸与 16 MP 的固定拒收条件；保留源分辨率和 8/16 位输入的浮点色彩转换。每次上传只保留条带。分行解码通过不代表任意大小图片已经能进入一张 GPU 纹理；实际设备纹理尺寸、地址范围、资源存活及内存分配仍需正确处理。

## 后续实现必须闭合的路径

1. 整个源文件只有一个逻辑画板和相机。源目录不是另一个编辑文档；Rust 仍使用共享 Document 和既有编辑/渲染语义。
2. 转换结果按稳定源对象与版本缓存到磁盘。视口取数、瓦片生产、编辑选取自动装入所需数据；不能要求用户手动载入另一工作集。
3. 缩小全览仍需显示全部素材。不能只载第一个素材，也不能把未加载对象的占位框或低清截图标为完整/清晰结果。取舍时区分布局提示、光学支持边界、采样依赖与实际像素覆盖。
4. 屏幕分块保持统一的世界坐标、采样相位、颜色/HDR 和四个相关采样。独立对象先做 RGBA8 解析再混合，不能自动当成原全场景的精确等价；跨对象蒙版、背景效果与重叠需要完整依赖证明。
5. 平铺的坐标映射必须与保存、撤销、重做、完整导出和重开一起实现。不能把窗口缺席的对象当作删除，也不能把合成画板或临时代理节点写入原对象补丁。
6. 相机、选框和滚动条使用全局画板范围。源版本、编辑版本、设备与采样密度仍需分别校验，过期任务不得发布为当前画面。

## 当前尚未完成

完整源现已通过原生快照进入同一个 GPU 画布；独立验证入口已显示全部 306 个素材并取得精确视口完成回执。正式工作区已接入相同入口、素材导航和全局滚动条。当前编辑仍需双击进入单个素材，再返回完整画板，尚不等于全场景直接编辑；平铺布局持久化和大于设备单纹理尺寸的虚拟图片也未完成。普通 codec、单个前端 live Document、部分图片/几何/修改 DTO 仍有既有工作预算或固定边界，需要继续迁移到分块路径。不能声明“所有上限已取消”、流畅性验收或 G2/G5 完成。

源实现、原生/前端测试、真实拓扑的 306 个素材索引和 64 成员导出核对见[验证记录](../testing/verification-topology-navigation-20261026/README.md)。完整构建与真实 GUI 结果应另列，不用测试替代实际呈现。

## 原生全量画板推进

2026-10-27 的后续候选已生成真实单画板原生快照：306 个素材、124447 节点、573894001 字节，原始归档仍不变。这一规模已不能依赖前端整份 JSON 字符串传输。新增原生流式读取和 SHA-256/身份核对入口，桌面主进程只向前端发会话、版本和窗口绑定的随机 token，不暴露快照路径。现已接入 GPU worker 与正式画布；原生全量模型与完整视口显示分别有证据，尚不能证明全场景编辑和连续交互性能。源转换缓存使已测 4022 节点大画板的第二次 native scene 调用从 2.478 秒降为 0.657 秒，但它不是交互帧率证据。

## 当前原生画布与相机约束

- 私有、宿主授权的源快照使用独立容量上下文，移除源模型节点/页面、两百万路径以及 GPU 每帧 262144 条累计 uniform 命令的拒收门槛。命令仍通过原有有界 arena 顺序提交；GPU 设备的实际纹理/存储尺寸与分配失败保持明确错误。
- 原生源任务不再由前端 30 秒、原生准备 120 秒的固定时长判为失败。只有私有快照成功载入的原生 lane 获得该行为；普通任务维持原协议。用户取消、线程退出、设备丢失与真实操作错误仍会结束任务。时间不等于进度，未完成任务始终显示正在绘制。
- 相机取消 2.5%–3200% 的固定产品范围。有效、有限的正缩放保持双精度；非法输入和数值溢出不发布为相机。全览可低于 2.5%，保存的相机不再截断到旧范围。特定缩放下物理 GPU 坐标和精确采样能力仍须实际验证。
- 2026-10-27 正式工作区 v15 已导入完整素材目录并显示单一源画布，首次 3200% 视口实际落在图标间空白，不能作为图标/阴影高倍渲染通过。后续固定参考视口另记。


2026-10-27 v17 后续 GUI 已完成固定“入库”图标 3200% 和返回 2.467% 全览的实际显示校验，见验证记录中的两张截图。冷图标首块约 28.64 秒，全览复杂瓦片约 59–62 秒，流畅性仍未通过；不能把“现在能显示”写成“现在不卡”。
