## 大曲线与大渐变的精度边界

普通 Boolean 保持已有 flo_curves 的 0.001 clipping accuracy。新增 dense 路径先将派生工作坐标精确乘以 2¹⁰，完成后除回；等效局部 clipping accuracy 收紧为 0.001 / 1024，以免固定 coincidence 容差吞并密集细节。没有用平滑或抽点缩小原始曲线。输入与输出受现有 131,072 个 render commands 限制，sweep 候选工作量另有上界；交点图也检查规模。稀疏轴由控制凸包计算，避免细长轮廓在单一轴上被误判为大量重叠。最初能输出的 1,226 命令版本不能视为正确性通过；后续固定全序后的粗容差候选也在独立 winding 检查中出现 436/1,763 不一致。收紧 dense 工作容差后得到 28,729 个输出曲线命令，1,763 个点零不一致、边界排除 0；保留 Boolean operation 和原始操作数。完整大画板 GUI 与保存仍独立验证。

33–64 色标路径通过参数纹理传输全部 offset/RGB/alpha，原有插值次序、舍入、色彩空间和四个相关样本不变。它是新的表示路径，不是简单删除 shader guard；未上传色标表的直接绘制路径不接收大色标列表。文档、动画、共享样式和自动化 descriptor 的范围同步。

1. 冻结源码、实际 WASM/native/JS 与 fixture 哈希；记录采集脚本首次缺图标资源与启动页等待失败，不把失败计入通过。

3. 重建实际加载的 WASM、native 和 Electron。Rust 改动之前的前端结果不能作为新内核验证。
4. 独立 Electron 重放“控件”页属性修改、撤销重做、缩放、反向缩放、拖动；分别保存 renderer/worker 火焰图。先做 sampler-on 诊断，再做 sampler-off 延迟，不能混作 A/B。
5. 原始大画板及两块 36 色标素材经真实入口重新导入、呈现、编辑、撤销、保存、完整导出；核对 64 个成员及未改成员字节。
6. 活跃窗口 `uiStalls=0` 沿用 G2；物理输入到像素目标、完整规模矩阵和跨平台验收未执行前保持 NOT_RUN/BLOCKED。单节点通过不能关闭整画板失败。

## 2026-10-24：按减少重复工作落地

1. **局部派生与跨边界增量**：`component_updates::State` 仅持有现有 Document 类型与单调回执。连续 Editor 提交发送 DocumentPatch；失效回执明确回退，校验失败原子拒绝。只重新展开受影响实例，传播嵌套定义依赖，并限制布局/Boolean 到相关页面根。绑定、变量模式、插槽、连接器等未证明可分离的依赖保持完整派生。全局准入和历史校验仍存在，不能称为所有阶段 O(修改量)。
2. **稳定中间结果**：有界 Boolean 几何缓存跨 resolve 存活；文档补丁保留可证明未变的拓扑索引。派生后再判定 camera prepare 的节点失效范围，避免将未经验证的旧几何当成最新结果。真实“控件”工作集的视口外实例宽度修改，从旧版本重建 149 个程序，变为新增构建 0、命中 149、保留 544 个节点；前后输出包 SHA-256 相同。该计数不依赖本机耗时比较。
3. **可取消准备**：大渐变分块与整块字段的 1,228,800 个浮点通道逐位一致。第一个实际让出执行权处注入取消时，旧路径已上传 4 个完整字段，新路径完整字段上传为 0；两者均按取消结束。它证明更早停止准备，不是物理拖动延迟指标。
4. **材质资源复用**：33–64 色标参数表保留全部 offset/RGB/alpha，按完整内容与色彩配置缓存；小列表保留原 uniform 路径。颜色、透明度或配置变化会重新建表。
5. **诊断重复扫描**：去除本地记录生成的重复 allowlist 扫描；接收端隐私与字段校验继续保留。仍需结合全应用火焰图判断剩余热点。

没有采用放大旧图块后等待 150 ms、降低大模糊分辨率、减少四采样或抬高 GPU 预算的方式。既有实验开关继续默认关闭。

## 完整素材回归发现的额外故障

- **工具条点击遮挡**：大画板已渲染且重命名成功，但底部撤销按钮被 Canvas SVG 层截获点击。给源工作区工具条明确 stacking 顺序后，真实鼠标点击撤销、重做与保存通过。没有使用强制点击绕过。
- **Boolean 比较器 panic**：36 色标素材同时包含另一个独立几何故障。`flo_curves 0.8.1` 的 ray comparator 使用成对 epsilon/overlap 比较，关系不传递，导致 native 的 `comparison function does not correctly implement a total order` 和 WASM `unreachable`。由 53 节点问题子树缩减成 3 个操作数、3.4 KiB 的确定回归样本；旧冻结 native 必现。局部 vendored 修复按 f64 射线参数全序排序，重叠边分组与进入/离开顺序仍由已有 winding 分类实现。109 个上游单元测试通过，四种 Boolean 运算与独立 polygon winding oracle 一致，原始操作数保持不变。没有用捕获异常或跳过节点掩盖失败。
- **测试定位修正**：实例展开后名字从 `icon备份 2` 变为组件名“地球”；旧回归脚本搜索了源名字。失败记录保留，修正仅影响测试定位。

硬件像素验证已覆盖 WebGPU 与 WebGL2 的 32/36/64 色标线性、径向渐变，含重复色标、透明度与超出 SDR 的浮点值：12 个用例均与 Rust 浮点输出逐位一致。该结果证明绘制路径；源导入、完整页面渲染和保存另行验收。

- **密集 Boolean 固定容差吞并细节**：只验证能渲染和外接框不足以证明结果正确。真实 57k 段输入的独立 polygon winding oracle 暴露了 436/1,763 个填充偏差。新增 dense 路径以 2¹⁰ 精确缩放派生坐标，在相同库规则下提高局部精度，然后除回；输出保留 28,729 曲线命令、1,763 点零不一致。采样 oracle 的边界排除阈值在修复前后均为 0.002，本次排除 0。原有编辑路径与 renderer 的四采样、HDR/export 不变。
- **源对象搜索结果晚回**：切换查询后旧的一行结果可能仍可点击；回归脚本只等待“结果数为 1”会点错同名画板。产品切换源导航请求时清除过期可点击行，测试按源 key 确认匹配的新回复；有延迟回复的 mounted 回归通过。
