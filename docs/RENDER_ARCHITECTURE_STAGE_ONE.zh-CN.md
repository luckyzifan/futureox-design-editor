# 渲染架构修复：第一阶段的边界

本阶段是可核验的局部重构，不代表已达到其他设计工具的完整架构或帧率水平。像素效果、导出、顺序文档更新、字体与图片所有权仍须保持原有约束。

## 已整合的职责边界

- 文档差量：只从完整差量或实际应用的补丁记录弱引用转换见证；最多追溯 32 步、4096 个节点 ID。没有足够证据时仍执行完整比较。根字段始终比较；只改根字段时不复制节点表。内核记录规范化使用写时复制，不修改旧快照。
- CPU 数据包：准备结果附带冻结的 lane、内核内部变更序号、已序列化选项和设置。只能消费一次，消费时复核序号、待处理变更和取消状态。该序号不是作者文档身份的证明，也不是 GPU 资源凭证。丢弃只处理 CPU 字节，不释放使用中的纹理或编码器。
- 取消隔离：可取消的物理编译不作为其他精确请求的共享所有者；加入不可取消编译的消费者独立取消等待，不能取消其他消费者。
- 稳定 lane 状态：画布与交互状态各自拥有稳定对象，不再靠一组全局字段保存、恢复。GPU 队列仍串行；没有默认启用跨 lane 的 GPU 所有权释放或穿插执行。
- 精确 CPU 瓦片缓存：两个所有者共用一个 LRU 和原有 128 MiB 总预算，而不是每 lane 各分配一个预算。所有者元数据纳入预算；局部文档、字体和损伤失效不清空另一所有者，设备和配置变化仍全局失效。仅缓存独立 CPU 字节，不保留转移后的 bitmap 或临时 GPU 纹理租约。
- 依赖与质量语义：复用已有编译节点判定和已知效果能力检查；未知可见效果保守拒绝复用。作者场景的边界计算仍只是估计，不授权安全复用。质量字段整合保持既有分支行为，不新增省略图层模糊、背景模糊或改变效果数学的权限。

## 测量可以说明什么

在实际导入的 19,287 节点文档上，每项 100 次局部 CPU 样本中，重复单节点差量比较中位数约为 13.21 ms → 0.0018 ms，跨九次编辑的差量约为 10.69 ms → 0.0026 ms，仅根字段应用补丁约为 7.27 ms → 0.0010 ms。这证明重复全表扫描被消除，不代表首次完整比较、节点表复制或端到端渲染延迟。

精确缓存的确定性模拟回放中，五次访问、每次两个瓦片，命中从 0 次增至 6 次，编译/栅格操作从 10 次减至 4 次。这只是保留 CPU 字节的缓存路径证据，不是设备耗时或真实 GPU 帧率。仅呈现 GPU 图像、CPU 缓冲区为零字节的路径不能据此保证命中；现有日志中的零命中也不必因此改变。

## 仍未完成的架构工作

- 内核直接签发、跨前后端统一的完整依赖证明。
- 在真实设备上验证安全的异步 GPU 所有权收缩、并行阶段和资源退休。
- 消除所有首次加载、布局、结构验证与大范围节点复制成本。
- 与参考工具进行真实 GPU、合成、显示扫描和输入到光子的同条件比较。

CPU 编译或字节一致性测试不能替代设备像素差分、导出对照和真实交互测量。停止交互后仍应恢复完整清晰度，设计中有意设置的模糊必须保留。

下一步有价值的同步边界是由权威 preparation worker 签发并验证的不透明文档见证，以减少同一文档 fork 时重新发送、解析整个大文档的成本。这需要显式协议、失败撤销和陈旧/不匹配验证，不能用客户端 revision ID 单独代替内容证明。本阶段不引入该协议捷径。

## 补丁后的精确 fork：实际文件验证

成功应用完整补丁后可重新建立精确来源证明；失败、陈旧回调、瞬时交互变换或超限会撤销复用，保留完整加载回退。前端保留有界补丁日志而非额外常驻的解析文档：最多 256 条、4 MiB UTF-16 补丁文本；画布来源最多 32 Mi 个 UTF-16 code units。结构与根字段修改仍按顺序应用，只有已存在节点的纯替换可保留最后值。原生续证输入和规范化临时字节各限制为 32 MiB，超限仅退回加载。原生路径先比较权威文档的精确规范序列化结果，再共享静态快照；字体、图像与 mip 配置约束不变。

同一 Rust 1.96.1 desktop-dev 编译配置、21,797,593 字节导入文件的云端 Node/stdio 对照中，对照组四个完整生命周期、最终组原始三个完整生命周期，补丁后交互准备（加载/内容证明加首次编译）每次总耗时的中位数约为 1483 ms → 931 ms，最终组范围 852–1086 ms。加载/证明阶段单独为 787 ms → 899 ms，反而变慢；首次编译约为 721 ms → 33 ms。分阶段中位数不可直接相加。最终组三次 fork 均成功；对照组四次均未 fork。该修复避免重复编译，但这一有界原生准备测试仍约为一秒。

选定 512×512 视图的 589,712 字节数据包哈希一致，但该次补丁未改变该视图可见字节，不能据此宣称完整像素一致性。原始最终组第四个生命周期在末次编译退出 137，原因未明，未计入完成样本；随后独立低保留重试成功，仅作恢复证据，不合并主结果，也不宣称完整稳定性。真实 Electron IPC、用户 GPU 与显示路径未测量；此结果不能宣称用户日志中的 6.17 秒加载已经解决，更不能把 WASM 内部的不同边界数字当作 Electron 加速比。
