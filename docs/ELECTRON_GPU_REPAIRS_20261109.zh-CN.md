## 修复

- 恢复 SQLite payload worker 传回的 Buffer 视图，沿用固定文档额度，消除自动保存误报容量不足。
- 仅在源 token、版本、owner、实际位图覆盖和当前素材范围有效时，让已认可原生区域穿透打开预览。使用重绑定后的 catalogue key，保留其他素材缩略图。
- 清晰标识依赖真实相机、采样密度与 ready 回执；第一张 ready 后继续更新状态。
- 蒙版 owner 和坐标纹理退休改用准确的增量/反向索引。
- 普通 SDR 显示的高倍图片 Gaussian 在确切的表面分配错误后按完整支持范围分条；保留四采样、六遍、原密度、效果与预算，HDR/精确输出不扩大准入。
- 可恢复预算错误保留有效 GPU 设备并清理滤镜 scratch。
- CPU 原始阴影与盒滤波恢复正确边界，保留证明成立的快速分支；CPU 空/粗帧不能认可原生覆盖。
- 完整源已有同源解码预览时，先完成目标密度瓦片，再预取粗页。高倍停止输入后，仅撤销未交付的可选滤镜预览，保留原任务完结、迟到载荷释放和文档同步边界。

保留 PR56/57 的覆盖场、位图保留、原生 JSON、重绑定/恢复及原文件保护。未整体开启实验开关。
