# Nomi 桌宠首次集成（NEXT，2026-10-20）

## 本次交付范围

设置 → 保存与范围可选择关闭、安静、互动；默认关闭，选项保存在本机浏览器偏好。开启后创建一个 240 × 280 的透明、点击穿透、不抢焦点的 Electron 窗口。安静模式仅绘制静态角色。互动模式使用 Futureox 自行编写的 Canvas 2D 变换动画，不运行 Nomi 的脚本、服务或原始动画引擎。

本次只有一张固定来源角色图；没有引入 Rive、VRM、AI、CLI、MCP、语音、模型下载、遥测或网络访问，也没有增加或安装 npm 依赖。现有 Electron 44.7.0 仍是桌面运行依赖。未改稳定版或发布目录。

### 实际动作映射

- idle：轻微上下呼吸
- edit → work：轻微摇摆，表示编辑
- save → nod：整张角色图轻微压缩和位移，表示保存完成
- undo → puzzled：整张角色图倾斜
- export → celebrate：整张角色图跳动和摇摆
- error → puzzled：整张角色图倾斜
- wave：渲染器已实现整图摇摆，目前没有公开触发入口

这些是自有简化反应，不是 Nomi 上游的分层手臂/表情动作，不代表已经移植或验证其 42 个 Rive 原生动作或 43 个 Sprite 动作。没有动作选择菜单、拖拽/抚摸、表情替换或语音。本次用于验证最小展示层与编辑语义连接，完整动画引擎需要后续独立实现与视觉验收。

编辑事件来自已提交的 Editor 修改，预览和取消不算提交；保存仅在桌面保存/工作区提交获得成功答复后触发；导出仅在结果发布成功后触发。仅传递白名单枚举字符串，不传文档、图像、文件名、坐标或凭证。前端同类事件 1,200 ms 内去重；主进程全局反应间隔至少 900 ms，突发只保留一个最高优先级事件，1,600 ms 后回 idle。导航期间清除待播事件，结束后不会补播旧动作。

## 隔离与资源边界

- 独立沙箱 BrowserWindow / renderer 执行环境、独立非持久 session、自有本地 design-pet 协议和受限 preload。
- 这不是独立操作系统应用或专属 GPU。Chromium GPU 服务、物理 GPU、驱动与桌面合成仍可能共享争用。没有修改编辑器 GPU flag 或 WebGPU 管线，也没有对编辑器截图或每帧拷贝。
- 动画调度属于宠物窗口，不使用编辑画布的 rAF。最多一个待执行 rAF、实际绘制频率不超过 30 FPS、DPR ≤ 1.5。高刷新率显示器仍可能产生更多 rAF 回调，但绘制受限。
- 窗口隐藏、编辑器最小化/关闭、系统休眠/锁屏、画布平移缩放、安静模式和系统减少动态效果时停止持续动画。锁屏与休眠独立计数，恢复系统不能覆盖仍锁屏的暂停原因。
- 默认窗口 backing store 上限为 360 × 420 像素（240 × 280 CSS，DPR 1.5）。RGBA 单表面算术量约 0.58 MiB，绝不是实测显存。图片、Chromium 进程、解码、合成和多缓冲还有额外开销。
- 拒绝导航、弹窗、权限请求、外部网络；Node integration 关闭，sandbox/contextIsolation/webSecurity 开启。主窗口 IPC 沿用精确 webContents + 主 frame + origin 校验；宠物 ready IPC 独立校验。
- 角色图加载失败、renderer 退出或 GPU 子进程异常会熔断关闭；10 秒内未 ready 也关闭。不会自动重启。明确关闭后再开启才允许重试。设置值是持久偏好；状态通过受限 IPC 事件单独反馈，创建窗口时显示启动中，收到受信 ready 后才确认，加载失败/超时/崩溃会显示暂不可用并提示先关闭再开启。状态通知带单调修订号，不轮询，不把启动请求成功当作实际显示成功。
