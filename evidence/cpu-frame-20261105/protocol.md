# 同相机 CPU 分块的单帧准备

在 37959392 加现有工作树上冻结原生内核 A。B 使用相同的依赖、工具链和 desktop-dev profile。准备数据仅在一次同步 render_linear 内有效。单块使用原路径，guard 相关的几何和每块的合成、路径、滤镜与取消检查沿用现有限制。

计时采用真实 117.sketch 与固定种子的稀疏矢量页。每份文档分别用同一相机渲染 512²、1024²、2048²，对应 1、4、16 个 512 像素的真实光栅块。每格两组 ABBA，每进程一次冷帧和两次暖帧，单进程、单内核、顺序运行。分别报告准备 wall 时间、整帧 wall 时间的暖样本中位数，以及独立进程 RSS 高水位的中位数和合成分配账本峰值。RSS 包含载入和输出缓冲。准备计时覆盖 backdrop 分析、帧计划、halo、zoom 支撑与几何准备，截止于分配第一张合成表面。探针仅加入 A/B 副本。

预设观察门为多块准备至少减少 5%，整帧回退超过 5% 或 RSS 增长超过 max(8 MiB, 5%) 单列调查。单块为对照。像素门为 A/B 全帧四通道 f32 原始位零差异，以及实际 PQ 16 位 PNG 像素和色彩信息一致。前景模糊、背景模糊、蒙版、径向缩放模糊各有去掉对应效果的对照，须在跨块接缝两侧观察到非零变化，HDR 须出现大于 1 的线性分量。遇到资源或取消错误沿用原错误，未测场景独立报告。

首轮 117 的 100% 相机为 (−1024.25, −256.5)。4 块基线触及 256 MiB 合成预算，保留原相机，分别核对两臂 4、16 块的拒绝。另增 50% 全页相机 (225.25, −160.375)，用相同的 752 节点原稿补齐 1、4、16 块计时。两套相机各自报告。首版稀疏页单块准备有回退，最终版把共享几何的查找编译在多块路径中，并降低页级扫描的取消轮询频率。本次修订在最终版计时前记录。

最终矩阵 117 的 4 块格子触及 RSS 观察线。追加一次独立的 BAAB、ABBA，选择同一格、同一二进制、相同默认额度与相同三帧。用 macOS `/usr/bin/time -l` 同时记录每个进程的 maximum resident set size 和 peak memory footprint，各臂对四个进程取中位数，另保留最大值。原矩阵读数保留。
