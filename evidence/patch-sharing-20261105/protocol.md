# 局部补丁对照口径 · 2026-11-05

基线是 main 的 37959392 加本轮开始时已有的工作树修改，候选仅改变节点存储和快照校验。两份原生 design-prepare 用同一工具链、默认 features、desktop-dev profile 和锁文件依赖构建。在同一台 Apple M2 Pro 上顺序运行，计时阶段不并发构建或读回像素。

- **结构判据**：保留一个旧 worker 后调整单节点宽度。未改节点和 ID 索引保持同一分配，旧 worker 继续给出原图；候选与完整载入的序列化字节、脏区及 RGBA 相符；非法编辑不发布文档、版本或字节回执。普通结构编辑、外部输入、原有资源额度和错误仍生效。
- **mapped 判据**：放置完成后至归档追加只做一次完整 native-source 校验；原始文档写入和复制后的迁移前缀仍须独立校验。两个写入入口的文件字节、描述符和重新载入结果完全相同。取消、损坏的记录或错误的描述符继续拒绝。
- **时间观察**：117.sketch 的“椭圆 66”从 5×5 改为 25×20；原始 20,082 节点 FIG 已导出的完整文档中，将指定 Path 的不透明度从 1 改为 0.25。均走桌面 Worker → 原生内核。在各自可见区域先单独验证改动有非零像素变化，正反脏区一致、逆补丁恢复原图、增量等于完整载入，再开始计时。每臂预热 3 次、6 组 ABBA 各 12 样本。分别取提交至脏区、提交至编包的中位数。以补丁阶段至少下降 5% 为该场景的速度目标；跨场景、GUI 旋转和内存峰值均不由这组数据推导。未过门的结果保留。
- **停止边界**：像素、字节、拒绝语义或资源隔离不符就停止该场景的计时。缺少完整输入、无法安全复现、未跑或预算拒绝均单列，不计为通过。桌面输入到显示、物理 GPU、导出全矩阵、33/100 ms 目标本轮另列。
